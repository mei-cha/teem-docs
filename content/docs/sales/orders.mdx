Halaman **Pesanan** digunakan oleh Administrator untuk memantau seluruh transaksi pemesanan barang di platform **Teem.id**, baik pesanan yang ditangani langsung oleh pusat (**Pesanan Saya**) maupun pesanan yang ditangani oleh mitra (**Pesanan Mitra**).

Melalui halaman ini, Admin dapat memproses pengiriman pesanan, menentukan metode pengiriman, memperbarui status pesanan, serta mengelola pengajuan pembatalan pesanan dari pelanggan.

---

## Tab Pesanan

Buka modul **Penjualan > Pesanan**. Di pojok kiri atas halaman terdapat dua tab:

| Tab | Keterangan |
| :--- | :--- |
| **Pesanan Saya** | Menampilkan pesanan yang ditangani langsung oleh Admin Pusat. |
| **Pesanan Mitra** | Menampilkan pesanan yang ditangani oleh mitra. Tab ini bersifat *read-only*: Admin hanya dapat melihat pesanan dan mencetak invoice. |

<Callout type="warn" title="Penting">
  Admin hanya dapat menangani (menerima, menolak, mencatat pembayaran, dan memproses pengiriman) pesanan pada tab **Pesanan Saya**, yaitu pesanan yang ditangani pusat. Pesanan pada tab **Pesanan Mitra** hanya dapat dilihat dan dicetak invoice-nya melalui tombol **Cetak Invoice**.
</Callout>

---

## Menyaring dan Mengunduh Data

### Filter Data

Gunakan deretan filter di bagian atas tabel untuk mempersempit daftar transaksi pesanan yang ingin ditampilkan.

| Filter | Fungsi |
| :--- | :--- |
| **Rentang Waktu** | Secara *default*, data menampilkan transaksi dalam rentang **30 Hari Terakhir**. Klik pilihan periode ini jika ingin mengubah rentang waktu data. |
| **Semua Pembayaran** | Menyaring transaksi berdasarkan metode atau status pembayaran. |
| **Tipe Pesanan** | Memfilter jenis pemesanan yang masuk. |
| **Semua Pengiriman** | Menyaring berdasarkan metode penyerahan barang. |
| **Semua Status** | Menyaring berdasarkan status alur pesanan. |
| **Cari invoice / nama...** | Kolom input di pojok kanan atas untuk mencari transaksi spesifik berdasarkan **Nomor Invoice** atau **Nama Pelanggan/Mitra**. |

### Export Data

Klik tombol **Export** untuk mengunduh rekapitulasi data pesanan hasil filter ke dalam berkas spreadsheet.

**Format struktur berkas ekspor spreadsheet:**

* **Prinsip 1 Baris Per Invoice:** Setiap 1 nomor invoice transaksi hanya dicatat dalam **1 baris tunggal** pada berkas spreadsheet.
* **Kolom Detail Produk:** Seluruh rincian item barang yang dibeli dalam invoice tersebut digabungkan ke dalam satu kolom khusus bernama **Detail Produk** dengan format penulisan `[Nama Produk]: [Kuantitas] [Satuan]` guna menjaga kerapian baris data.

## Halaman Detail Pesanan

Klik **nomor invoice** pada kolom **Pelanggan** untuk membuka halaman detail pesanan tersebut.

Tombol **Cetak Invoice** selalu tersedia di pojok kanan atas halaman detail, apa pun status pesanannya. Pada pesanan mitra, **Cetak Invoice** adalah satu-satunya tindakan yang tersedia. Untuk pesanan yang ditangani pusat, tombol lain muncul menyesuaikan kondisi pesanan (lihat bagian **Menerima atau Menolak Pesanan Baru** dan **Mencatat Pembayaran Manual**).

Halaman detail menampilkan informasi berikut:

| Bagian | Isi |
| :--- | :--- |
| **Header Pesanan** | Nomor invoice, waktu pemesanan, dan status pesanan. |
| **Informasi Pelanggan & Pengiriman** | Nama pelanggan beserta level akunnya, pihak yang menangani pesanan (**Ditangani Oleh**), metode pengiriman, dan alamat tujuan. |
| **Daftar Produk** | Produk yang dipesan beserta jumlah, harga, dan subtotal. |
| **Ringkasan Pembayaran** | Subtotal produk, ongkos kirim, biaya layanan, diskon kupon, total, serta metode dan status pembayaran. |
| **Catatan Pesanan** | Catatan dari pelanggan untuk pesanan tersebut. |

## Menangani Pesanan

Bagian ini menjelaskan tindakan Admin pada tab **Pesanan Saya** (pesanan yang ditangani pusat) sesuai kondisi pesanan. Pesanan pada tab **Pesanan Mitra** hanya dapat dilihat dan dicetak invoice-nya, sehingga tindakan di bawah ini tidak berlaku untuknya. Kerjakan bagian yang sesuai dengan kondisi pesanan yang sedang ditangani.

### Menerima atau Menolak Pesanan Baru

Pesanan yang baru masuk pada tab **Pesanan Saya** menampilkan status pengiriman **Menunggu** pada kolom **Pengiriman**. Pada kolom **Aksi** (dan juga pada header halaman detail pesanan), pesanan dengan status ini menampilkan dua tombol:

| Tombol | Fungsi |
| :--- | :--- |
| **Terima** | Menerima pesanan agar dapat dilanjutkan ke proses berikutnya. |
| **Tolak** | Menolak pesanan tersebut. Setelah diklik, akan muncul form untuk mengisi alasan penolakan. |

Setelah pesanan diterima, pesanan langsung lanjut ke tahap berikutnya. Tombol pada kolom **Aksi** menyesuaikan tipe pengiriman pesanan:

| Tipe Pengiriman | Tombol Berikutnya | Keterangan |
| :--- | :--- | :--- |
| **Dikirim Kurir** | **→ Proses** | Membuka form untuk menentukan ekspedisi. Lihat bagian **Pengiriman melalui Ekspedisi**. |
| **Diambil Sendiri** | **→ Siap Diambil** | Lihat bagian **Pesanan Ambil Sendiri**. |

### Mencatat Pembayaran Manual

Untuk pesanan berstatus **Menunggu** dan **Belum Bayar** yang pembayarannya tidak melalui *payment gateway* Teem.id, halaman detail pesanan menampilkan tombol hijau **Proses Bayar**. Tombol ini digunakan Admin untuk mencatat bahwa pesanan sudah dilunasi di luar sistem pembayaran.

Tombol **Proses Bayar** hanya tersedia untuk pesanan yang ditangani pusat (tab **Pesanan Saya**).

1. Buka halaman detail pesanan dengan mengklik nomor invoice.
2. Klik tombol **Proses Bayar**.
3. Pada jendela **Proses Pembayaran**, periksa **Invoice** dan **Total Nilai** pesanan.
4. Isi kolom **Metode Pembayaran** dengan metode yang digunakan, misalnya *Transfer BCA*, *Tunai*, atau *QRIS*.
5. Klik **Proses** untuk menyimpan, atau **Batal** untuk menutup jendela tanpa menyimpan.

Setelah disimpan, status pembayaran pesanan otomatis berubah menjadi **Lunas**.

Proses ini hanya memperbarui status pembayaran. Keputusan **Terima** atau **Tolak** pesanan tetap dilakukan secara terpisah.

### Pengiriman melalui Ekspedisi

Pesanan berstatus **Diproses** dapat ditangani dengan dua cara, tergantung metode pengiriman yang dipilih pelanggan. Bagian ini untuk pesanan yang akan dikirim melalui ekspedisi.

1. Pada tab **Pesanan Saya**, cari pesanan tersebut.
2. Klik tombol **→ Proses** pada kolom **Aksi**.
3. Form **Proses Pengiriman** akan muncul.

#### Metode Penyerahan

Pilih salah satu metode penyerahan paket:

- **Pickup:** Paket akan diambil oleh kurir ekspedisi dari lokasi asal atau gudang perusahaan.
- **Drop Off:** Paket diantar oleh tim perusahaan ke gerai ekspedisi.

Jika memilih **Pickup**, tentukan jadwal penjemputan pada pilihan **Jadwal Pickup**. Pilihan ini tidak tersedia jika menggunakan metode **Drop Off**.

#### Data Paket

- Masukkan data paket berupa **Berat (gram)**, **Nilai Barang (Rp)**, **Panjang (cm)**, **Lebar (cm)**, dan **Tinggi (cm)**.
- Centang **Gunakan Asuransi** jika ingin menggunakan asuransi pengiriman.

<Callout type="warn" title="Penting">
  Jika total **Nilai Barang (Rp)** melebihi **Rp 500.000**, **Gunakan Asuransi** wajib dipilih untuk memberikan perlindungan terhadap risiko kerusakan atau kehilangan barang selama pengiriman.
</Callout>

Setelah data terisi, klik tombol **Cek Harga Pengiriman**.

#### Layanan Ekspedisi

1. Sistem akan menampilkan pilihan layanan ekspedisi beserta estimasi waktu dan biaya pengiriman.
2. Pilih layanan yang sesuai.
3. Klik tombol **Proses Pengiriman** di pojok kanan bawah untuk melanjutkan proses pengiriman.

### Pesanan Ambil Sendiri

Bagian ini untuk pesanan berstatus **Diproses** dengan metode **Diambil Sendiri**.

1. Klik tombol **→ Siap Diambil** pada kolom **Aksi**.
2. Pelanggan akan mendapatkan informasi bahwa barang sudah dapat diambil di lokasi.
3. Pesanan langsung berstatus **Selesai**.

### Cetak Resi dan Tracking

Setelah pengiriman diproses, kolom **Pengiriman** menampilkan metode pengiriman, status pengiriman, serta layanan ekspedisi yang dipakai. Tombol pada kolom **Aksi** menyesuaikan status pesanan:

| Status Pengiriman | Tombol Aksi | Fungsi |
| :--- | :--- | :--- |
| **Diproses** | **Cetak Resi** | Mencetak resi pengiriman pesanan. |
| **Dikirim** | **Tracking** | Melacak status pengiriman paket. |

## Pembatalan Pesanan

Apabila terdapat pembatalan pesanan yang ditangani pusat, namun sudah berstatus **Diproses**, pembatalan tersebut memerlukan persetujuan (*approval*) dari Administrator.

### Membuka Halaman Pembatalan

1. Pada tab **Pesanan Saya**, klik tombol berwarna merah **Pembatalan Pesanan** di pojok kanan atas.
2. Sistem akan mengarahkan (*redirect*) ke halaman khusus **Pembatalan Pesanan**.
3. Secara *default*, daftar pengajuan pembatalan akan langsung disaring pada status **Menunggu** (pengajuan baru yang membutuhkan tindakan Admin).

### Filter Status Pembatalan

Pengguna dapat mengubah penyaringan tampilan dengan memilih opsi status pada dropdown:

| Status | Keterangan |
| :--- | :--- |
| **Menunggu** | Menampilkan pengajuan pembatalan yang belum diproses. |
| **Disetujui** | Menampilkan daftar pengajuan pembatalan yang disetujui oleh Admin. |
| **Ditolak** | Menampilkan daftar pengajuan pembatalan yang ditolak oleh Admin. |
| **Semua Status** | Menampilkan seluruh riwayat pengajuan pembatalan. |

### Menyetujui atau Menolak Pengajuan

Pada kolom **Aksi**, Admin dapat meninjau **Alasan Pembatalan** lalu memilih untuk menyetujui (**Disetujui**) atau menolak (**Ditolak**) pengajuan pembatalan tersebut.

## Referensi Tabel

### Tabel Pesanan Utama

| Kolom | Fungsi dan Keterangan |
| :--- | :--- |
| **Pelanggan** | Menampilkan nama pembeli, kode level akun, dan nomor invoice. |
| **Produk Dibeli** | Menampilkan nama produk, jumlah unit, dan harga setiap produk. |
| **Pembayaran** | Menampilkan total pembayaran, status pembayaran (**Lunas** atau **Belum Bayar**), dan metode pembayaran. |
| **Ditangani** | Menampilkan pihak yang menangani pesanan, yaitu **Pusat** atau nama mitra. |
| **Pengiriman** | Menampilkan metode pengiriman dan status pengiriman, seperti **Menunggu**, **Diproses**, **Dikirim**, **Siap Diambil**, **Selesai**, atau **Dibatalkan**. Untuk pengiriman ekspedisi, ditampilkan juga layanan yang dipakai. |
| **Waktu** | Menampilkan waktu sejak transaksi dibuat. |
| **Aksi** | Menampilkan tombol untuk memproses pesanan, seperti **Terima**, **Tolak**, **→ Proses**, **→ Siap Diambil**, **Cetak Resi**, atau **Tracking**. |

### Tabel Halaman Pembatalan Pesanan

| Kolom | Fungsi dan Keterangan |
| :--- | :--- |
| **Pesanan** | Nomor invoice transaksi pesanan yang diajukan pembatalan. |
| **Pembeli** | Nama akun pelanggan pembuat pesanan. |
| **Diajukan Oleh** | Pihak yang mengusulkan pembatalan transaksi. |
| **Produk** | Rincian item produk yang ada di dalam pesanan. |
| **Total** | Total nominal transaksi pesanan. |
| **Alasan Pembatalan** | Alasan/keterangan yang diisi pelanggan saat mengajukan pembatalan. |
| **Status** | Status pengajuan pembatalan (**Menunggu**, **Disetujui**, **Ditolak**). |
| **Diajukan** | Waktu dan tanggal pengajuan pembatalan dikirim. |
| **Aksi** | Tombol persetujuan (*Approve*) atau penolakan (*Reject*) terhadap pengajuan pembatalan. |
