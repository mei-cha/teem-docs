Halaman **Leaderboard Poin** digunakan oleh Admin untuk memantau peringkat mitra atau konsumen berdasarkan perolehan poin imbalan (*reward points*) pada platform **Teem.id**, menelusuri rincian mutasi riwayat transaksi poin milik setiap pengguna, serta **menambahkan poin secara manual** kepada satu atau banyak penerima.

Data peringkat ini berguna untuk analisis loyalitas pengguna, evaluasi performa mitra, serta acuan pemberian apresiasi/reward periode tertentu.

---

## Cara Mengakses Halaman Leaderboard Poin

Bagi Admin yang ingin meninjau peringkat loyalitas poin pengguna, ikuti langkah navigasi berikut:

1. Pada bilah navigasi kiri (*sidebar*), buka modul **Kupon & Poin > Leaderboard Poin**.
2. Sistem akan menampilkan tabel daftar peringkat perolehan poin pengguna.

## Perbedaan Opsi Tampilan Mode Poin

Di pojok kiri atas tabel, terdapat dua tombol beralih (*tab toggle*) mode kalkulasi poin:

* **Saldo Poin Saat Ini:** Menampilkan sisa poin bersih yang **masih dimiliki dan belum ditukarkan** (*redeem*) oleh pengguna saat ini. Nilai bersifat dinamis dan dapat berkurang jika pengguna menukarkan poin.
* **Total Poin (Lifetime):** Menampilkan **akumulasi seluruh poin** yang pernah didapatkan pengguna sepanjang riwayat akunnya terbuat di sistem. Nilai bersifat akumulatif murni dan tidak berkurang meskipun poin telah ditukarkan.

## Panduan Pengoperasian Leaderboard & Drill-Down Riwayat

Admin dapat menyaring peringkat pengguna, meninjau riwayat mutasi poin secara terperinci, dan menambahkan poin manual:

### 1. Pencarian & Navigasi Mode Peringkat

* **Beralih Mode:** Klik tab **Saldo Poin Saat Ini** atau **Total Poin (Lifetime)** untuk menyesuaikan acuan pengurutan tabel.
* **Pencarian Cepat:** Gunakan kolom input **Cari nama mitra / pengguna...** di pojok kanan atas tabel untuk menemukan posisi akun spesifik.
* **Tambah Poin:** Klik tombol **Tambah Poin** (merah) di samping kolom pencarian untuk membuka halaman **Tambah Poin Manual**.

---

### 2. Meninjau Detail Riwayat Transaksi Poin (Drill-Down)

1. Klik pada **Nama Pengguna** pada tabel leaderboard untuk beralih ke halaman **Riwayat Transaksi Poin**.

2. Pada bagian *header* profil, tinjau informasi **Level Mitra** dan sisa **Saldo Poin Saat Ini**.
3. Pada tabel riwayat mutasi, periksa penambahan atau pengurangan poin:
   * **Masuk (+):** Poin bertambah (badge hijau), misalnya dari transaksi pembelanjaan atau penambahan poin manual oleh Admin.
   * **Keluar (-):** Poin berkurang (badge merah) akibat penggunaan potongan harga saat *checkout*.
4. Setiap baris transaksi menyajikan sisa saldo setelah mutasi (**Saldo Sesudah**), serta stempel **Waktu** transaksi.

### 3. Menambah Poin Secara Manual

Fitur ini digunakan untuk memberikan poin langsung kepada pengguna di luar transaksi pembelanjaan, misalnya bonus pencapaian target, kompensasi, atau apresiasi khusus.

Klik tombol **Tambah Poin** di pojok kanan atas halaman Leaderboard Poin. Sistem akan membuka halaman **Tambah Poin Manual**.

**Langkah-langkah:**

1. **Isi Tanggal:** Tanggal pencatatan poin. Secara bawaan terisi tanggal hari ini dan dapat diubah melalui ikon kalender.
2. **Isi Keterangan:** Catatan alasan pemberian poin (contoh: *Bonus target bulan Oktober 2026*). Keterangan ini tercatat pada riwayat transaksi poin penerima.
3. **Pilih Penerima** pada panel kiri:
   * Gunakan kolom **Cari nama / email / level...** untuk menemukan akun tertentu.
   * Centang akun yang ingin diberi poin. Setiap baris menampilkan nama, email, level (misal: konsumen), dan saldo poin saat ini.
   * Centang **Pilih semua** untuk memilih seluruh akun yang tersedia (jumlah ditampilkan di samping label, misal: *110*).
   * Jumlah akun terpilih tampil di pojok kanan atas panel (misal: *1 dipilih*).
4. **Tentukan Poin per Penerima** pada panel kanan:
   * Akun yang dipilih otomatis muncul di daftar **Poin per Penerima**. Isi jumlah poin pada kolom di sebelah nama masing-masing penerima.
   * Untuk memberi jumlah yang sama kepada semua penerima, isi kolom **Poin sama untuk semua**, lalu klik **Terapkan**.
   * Klik ikon **X** di samping kolom poin untuk mengeluarkan satu penerima dari daftar, atau klik **Hapus semua** untuk mengosongkan seluruh pilihan.
5. Periksa kembali tanggal, keterangan, dan nominal poin setiap penerima, lalu simpan untuk memproses penambahan poin.

<Callout type="warn" title="Periksa Sebelum Menyimpan">
  Pastikan jumlah poin pada setiap penerima sudah terisi dan tidak bernilai 0. Poin yang telah ditambahkan akan langsung tercatat sebagai mutasi **Masuk (+)** pada riwayat transaksi poin penerima dan memengaruhi peringkat di leaderboard.
</Callout>

## Struktur Tabel Leaderboard & Riwayat

### 1. Tabel Utama Leaderboard

| Kolom | Fungsi & Keterangan |
| :--- | :--- |
| **Peringkat** | Urutan posisi peringkat pengguna (dimulai dari peringkat 1). |
| **Nama** | Nama lengkap akun pengguna/mitra (dapat diklik untuk melihat riwayat transaksi poin). |
| **Level** | Badge indikator jenjang keanggotaan akun (distributor, agen, konsumen). |
| **Saldo Poin / Total Poin** | Jumlah akumulasi poin pengguna (menyesuaikan dengan mode tab yang aktif). |

### 2. Tabel Detail Riwayat Transaksi Poin

| Kolom | Fungsi & Keterangan |
| :--- | :--- |
| **Tipe** | Indikator jenis mutasi poin (**Masuk (+)** atau **Keluar (-)**). |
| **Poin** | Nominal penambahan atau pengurangan jumlah poin. |
| **Saldo Sesudah** | Sisa kalkulasi saldo poin pengguna setelah transaksi terjadi. |
| **Keterangan / Ref** | Catatan alasan mutasi poin beserta nomor ID invoice/referensinya. Untuk poin manual, berisi keterangan yang diisi Admin. |
| **Waktu** | Informasi stempel waktu kapan transaksi poin tercatat. |

### 3. Elemen Halaman Tambah Poin Manual

| Elemen | Fungsi & Keterangan |
| :--- | :--- |
| **Tanggal** | Tanggal pencatatan penambahan poin (default: hari ini). |
| **Keterangan** | Catatan alasan pemberian poin. |
| **Pilih Penerima** | Daftar akun yang dapat dipilih, dilengkapi pencarian (nama / email / level), opsi Pilih semua, dan penghitung jumlah terpilih. |
| **Poin sama untuk semua + Terapkan** | Mengisi jumlah poin yang sama ke seluruh penerima terpilih sekaligus. |
| **Poin per Penerima** | Daftar penerima terpilih beserta kolom nominal poin masing-masing dan ikon X untuk menghapus. |
| **Hapus semua** | Mengosongkan seluruh penerima terpilih. |
