Halaman **Import Stok** digunakan oleh Administrator untuk mengunggah dan memperbarui data stok dalam jumlah banyak ke gudang perusahaan menggunakan berkas spreadsheet (Excel/CSV).

Fitur ini mempermudah pencatatan stok secara sekaligus tanpa perlu memasukkan data produk satu per satu.

<Callout type="warn" title="Prasyarat Sebelum Impor">
  - **Produk dan Gudang:** Pastikan produk dan gudang sudah terdaftar di sistem sebelum melakukan impor.
  - **Satuan Terkecil:** Jumlah stok yang diinput wajib menggunakan satuan terkecil produk.
</Callout>

---

## Alur Melakukan Import Stok

Proses impor stok dilakukan melalui 4 tahap berikut.

### Langkah 1: Membuka Halaman dan Mengunduh Template

1. Buka modul **Pembelian > Stok Perusahaan**.
2. Di pojok kanan atas halaman, klik tombol **Import Stok**.
3. Klik tombol **Download Template**. Berkas spreadsheet akan otomatis terunduh ke perangkat.

---

### Langkah 2: Mengisi Data Stok

Buka berkas yang telah diunduh, lalu lengkapi data stok sesuai ketentuan berikut.

#### Struktur Kolom Template

| Header Kolom | Deskripsi Pengisian |
| :--- | :--- |
| **SKU Produk** | Kode unik produk (Wajib). |
| **Nama Gudang** | Nama gudang tempat stok disimpan (Wajib). |
| **Jumlah Stok** | Jumlah stok dalam satuan terkecil produk, berupa angka lebih dari 0 (Wajib). |

---

### Langkah 3: Mengunggah Berkas

1. Kembali ke halaman **Import Stok** di panel Administrator.
2. Klik tombol **Upload** di sebelah tombol **Download Template**.
3. Pilih berkas spreadsheet yang telah diisi.
4. Tunggu hingga sistem selesai membaca dan memvalidasi data.

---

### Langkah 4: Memeriksa Hasil Validasi dan Menyelesaikan Impor

Setelah berkas diunggah, periksa indikator validasi di atas tabel:

- **Indikator Valid:** Menampilkan jumlah baris data yang lolos verifikasi dan siap dimasukkan ke gudang.
- **Indikator Bermasalah:** Menampilkan jumlah baris data yang mengalami kendala.

#### Meninjau Tabel Validasi

| Kolom | Keterangan |
| :--- | :--- |
| **Baris** | Menunjukkan nomor baris data pada berkas Excel. |
| **SKU** | Kode produk yang sedang diverifikasi. |
| **Gudang** | Nama gudang tempat stok akan disimpan. |
| **Jumlah Cut-off** | Jumlah stok produk yang diinput. |
| **Status** | Menampilkan hasil validasi data atau alasan jika terjadi kesalahan. |

#### Menyelesaikan Impor

- Jika terdapat data bermasalah pada kolom **Status**, perbaiki data tersebut pada berkas Excel, lalu unggah kembali.
- Jika seluruh data sudah valid, klik tombol **Import** di pojok kanan bawah untuk memasukkan data stok ke dalam sistem.

## Panduan Mengatasi Masalah Validasi

Apabila sistem menampilkan pesan kesalahan pada tabel validasi, gunakan tabel berikut untuk mengetahui penyebab dan cara mengatasinya.

### 1. Masalah SKU dan Produk

| Pesan Error Sistem | Penyebab Utama | Solusi Penanganan |
| :--- | :--- | :--- |
| SKU kosong | Kolom **SKU Produk** tidak diisi. | Isi kode SKU produk yang akan ditambahkan stoknya. |
| SKU "[kode]" belum terdaftar di menu Produk | Kode SKU tidak ditemukan pada data produk di sistem. | Daftarkan produk terlebih dahulu melalui **Produk > Produk**, atau periksa kembali penulisan SKU pada berkas Excel. |

### 2. Masalah Gudang

| Pesan Error Sistem | Penyebab Utama | Solusi Penanganan |
| :--- | :--- | :--- |
| Nama Gudang kosong | Kolom **Nama Gudang** tidak diisi. | Isi nama gudang tempat stok akan disimpan. |
| Gudang "[nama]" tidak ditemukan | Nama gudang tidak sesuai dengan data gudang di sistem. | Periksa data gudang melalui **Master Data > Gudang**, lalu pastikan penulisan nama gudang pada berkas Excel sudah sesuai. |

### 3. Masalah Data dan Jumlah Stok

| Pesan Error Sistem | Penyebab Utama | Solusi Penanganan |
| :--- | :--- | :--- |
| Kombinasi SKU + Gudang duplikat di file ini (baris X, Y) | Produk yang sama untuk gudang yang sama ditulis lebih dari satu kali dalam berkas Excel. | Gabungkan jumlah stok menjadi satu baris dan hapus data duplikat. |
| Jumlah Stok kosong | Kolom jumlah stok tidak diisi. | Isi jumlah stok produk. |
| Jumlah Stok "[nilai]" tidak valid (harus angka > 0) | Jumlah stok berupa angka 0, angka negatif, teks, atau simbol yang tidak sesuai. | Masukkan jumlah stok dalam bentuk angka positif, misalnya 1200. |

---

## Ringkasan Fungsi Elemen Utama

| Elemen | Jenis | Fungsi Utama |
| :--- | :--- | :--- |
| **Download Template** | Tombol | Mengunduh format berkas spreadsheet untuk pengisian stok. |
| **Upload** | Tombol | Mengunggah berkas Excel yang telah diisi. |
| **Badge Valid dan Bermasalah** | Indikator | Menampilkan jumlah data yang valid dan bermasalah. |
| **Kolom Status Tabel** | Informasi Status | Menampilkan hasil validasi atau alasan terjadinya kesalahan. |
| **Tombol Import** | Eksekusi | Memasukkan data stok yang telah lolos validasi ke dalam sistem. |

---

> **Tips**  
> Pastikan penulisan SKU dan nama gudang pada berkas Excel sesuai dengan data yang sudah terdaftar di sistem agar proses validasi berjalan dengan lancar.
