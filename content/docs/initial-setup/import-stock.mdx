Halaman **Import Stok Perusahaan** digunakan oleh Administrator untuk mengunggah dan memperbarui saldo persediaan barang (*stock cut-off*) dalam jumlah banyak sekaligus ke gudang perusahaan menggunakan berkas spreadsheet (Excel/CSV).

Fitur ini mempermudah pencatatan persediaan secara kolektif tanpa perlu menginput data produk satu per satu secara manual.

---

## Cara Mengakses Halaman Import Stok

Bagi Administrator yang baru pertama kali menggunakan fitur ini, ikuti langkah navigasi berikut untuk menuju ke halaman impor:

1. Pada bilah navigasi kiri (*sidebar*), buka modul **Pembelian > Stok Perusahaan**.
2. Di pojok kanan atas halaman **Stok Perusahaan**, klik tombol **Import Stok**.
3. Sistem akan mengarahkan (*redirect*) Anda secara langsung ke halaman utama **Import Stok**.

## Panduan Penggunaan & Pengisian Berkas

Setelah berada di halaman **Import Stok**, Anda dapat mengunduh berkas acuan (*template*), mengisi data persediaan, dan memvalidasi isi berkas sebelum disimpan ke sistem.

<Callout type="warn" title="Prasyarat Sebelum Impor">
  1. Pastikan produk sudah terdaftar pada master data modul **Produk**.
  2. Pastikan gudang tujuan sudah terdaftar pada modul **Master Data > Gudang**.
  3. Jumlah stok wajib diinput menggunakan **satuan terkecil produk**.
</Callout>

### 1. Mengunduh & Mengisi Berkas Template

Gunakan tombol **Download Template** pada bagian atas untuk mendapatkan format spreadsheet acuan resmi, lalu lengkapi kolom-kolomnya sesuai ketentuan berikut:

| Header Kolom | Deskripsi Pengisian |
| :--- | :--- |
| **SKU Produk** | Kode unik identifikasi produk yang terdaftar di sistem (*Wajib*). |
| **Nama Gudang** | Nama gudang tempat persediaan barang disimpan (*Wajib*). |
| **Jumlah Stok** | Kuantitas persediaan dalam **satuan terkecil produk** (angka bulat > 0, *Wajib*). |

---

### 2. Mengunggah Berkas & Memeriksa Hasil Validasi

Setelah berkas diisi, klik tombol **Upload** berwarna merah untuk memproses data. Sistem akan memverifikasi isi berkas dan menampilkan hasilnya pada tabel validasi:

- **Indikator Ringkasan:** Menampilkan jumlah baris data **Valid** (siap dimasukkan ke gudang) dan **Bermasalah** (perlu diperbaiki).
- **Tabel Peninjauan:** Menampilkan rincian nomor baris (*Baris*), SKU, Gudang, Jumlah Cut-off, serta pesan detail pada kolom **Status** jika terdapat kesalahan.
- **Eksekusi Akhir:** Jika seluruh data sudah valid, klik tombol **Import** di pojok kanan bawah untuk memasukkan data stok secara resmi ke dalam gudang perusahaan.

---

## Panduan Mengatasi Masalah Validasi

Apabila sistem menampilkan pesan kesalahan pada tabel validasi, gunakan tabel acuan berikut untuk mengetahui penyebab dan cara solusinya:

### 1. Masalah SKU dan Produk

| Pesan Error Sistem | Penyebab Utama | Solusi Penanganan |
| :--- | :--- | :--- |
| SKU kosong | Kolom **SKU Produk** tidak diisi. | Isi kode SKU produk yang akan ditambahkan stoknya. |
| SKU "[kode]" belum terdaftar di menu Produk | Kode SKU tidak ditemukan pada data produk di sistem. | Daftarkan produk terlebih dahulu melalui **Produk > Produk**, atau periksa kembali penulisan SKU pada berkas Excel. |

### 2. Masalah Gudang

| Pesan Error Sistem | Penyebab Utama | Solusi Penanganan |
| :--- | :--- | :--- |
| Nama Gudang kosong | Kolom **Nama Gudang** tidak diisi. | Isi nama gudang tempat stok akan disimpan. |
| Gudang "[nama]" tidak ditemukan | Nama gudang tidak sesuai dengan data gudang di sistem. | Periksa data gudang melalui **Master Data > Gudang**, lalu pastikan penulisan nama gudang pada berkas Excel sudah sesuai. |

### 3. Masalah Data dan Jumlah Stok

| Pesan Error Sistem | Penyebab Utama | Solusi Penanganan |
| :--- | :--- | :--- |
| Kombinasi SKU + Gudang duplikat di file ini (baris X, Y) | Produk yang sama untuk gudang yang sama ditulis lebih dari satu kali dalam berkas Excel. | Gabungkan jumlah stok menjadi satu baris dan hapus data duplikat. |
| Jumlah Stok kosong | Kolom jumlah stok tidak diisi. | Isi jumlah stok produk. |
| Jumlah Stok "[nilai]" tidak valid (harus angka > 0) | Jumlah stok berupa angka 0, angka negatif, teks, atau simbol yang tidak sesuai. | Masukkan jumlah stok dalam bentuk angka positif (misalnya `1200`). |

---

## Ringkasan Fungsi Elemen Utama

| Elemen | Jenis | Fungsi Utama |
| :--- | :--- | :--- |
| **Download Template** | Tombol | Mengunduh format berkas spreadsheet resmi untuk pengisian stok. |
| **Upload** | Tombol | Mengunggah berkas Excel yang telah diisi. |
| **Badge Valid dan Bermasalah** | Indikator | Menampilkan jumlah data yang valid dan bermasalah. |
| **Kolom Status Tabel** | Informasi Status | Menampilkan hasil validasi atau alasan terjadinya kesalahan. |
| **Tombol Import** | Eksekusi | Memasukkan data stok yang telah lolos validasi ke dalam sistem. |
