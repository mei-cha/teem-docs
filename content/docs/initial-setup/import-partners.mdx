Halaman **Import Mitra** digunakan oleh Administrator untuk memasukkan data mitra dalam jumlah banyak (*bulk import*) secara sekaligus menggunakan berkas spreadsheet (Excel/CSV).

Fitur ini mempermudah proses mendaftarkan atau menyelaraskan status keanggotaan mitra lama ke dalam sistem **Teem.id** tanpa perlu menginput data satu per satu secara manual.

---

## Alur Melakukan Import Data Mitra

Proses impor data mitra wajib mengikuti alur 4 tahap urut berikut agar data dapat tervalidasi dengan benar oleh sistem:

### Langkah 1: Mengunduh Format Berkas (Download Template)
1. Buka modul **Kemitraan > Mitra**, lalu klik tombol **Import Mitra** (atau akses halaman impor).
2. Di bagian atas kotak instruksi, klik tombol **Download Template** berkas.
3. Berkas *template* spreadsheet akan otomatis terunduh ke komputer Anda.

---

### Langkah 2: Mengisi Kolom Data Spreadsheet
Buka berkas yang telah diunduh, lalu lengkapi kolom-kolom data mitra sesuai petunjuk formatnya.

#### Rincian Struktur Kolom Template:

| Header Kolom | Deskripsi Pengisian |
| :--- | :--- |
| **Email** | Alamat email mitra terdaftar (*Wajib*). |
| **Level Mitra** | Tingkatan jenjang kemitraan (*Wajib*). |
| **NIK** | Nomor Induk Kependudukan 16 digit angka (*Wajib*). |
| **NPWP** | Nomor Pokok Wajib Pajak mitra (*Opsional*). |
| **Alamat Lengkap** | Alamat domisili atau lokasi jalan/nomor rumah (*Wajib*). |
| **Provinsi** | Nama provinsi domisili (*Wajib*). |
| **Kota/Kabupaten** | Nama kota atau kabupaten (*Wajib*). |
| **Kecamatan** | Nama kecamatan (*Wajib*). |
| **Desa/Kelurahan** | Nama desa atau kelurahan (*Wajib*). |
| **Latitude** | Koordinat garis lintang peta, rentang `-90` s/d `90` (*Opsional*). |
| **Longitude** | Koordinat garis bujur peta, rentang `-180` s/d `180` (*Opsional*). |
| **Nama Bank** | Nama atau kode bank resmi yang terdaftar di sistem (*Opsional*). |
| **Nomor Rekening** | Nomor rekening bank atau e-wallet mitra (*Wajib jika Nama Bank diisi*). |
| **Nama Pemilik Rekening** | Nama pemilik sesuai yang tertera pada buku tabungan (*Opsional*). |
| **Tanggal Mulai Kontrak** | Tanggal awal berlakunya masa aktif kemitraan dengan format standar (*Wajib*). |
| **Tanggal Berakhir Kontrak** | Tanggal kadaluarsa kontrak dengan format standar (*Kosongkan jika tanpa batas/selamanya*). |

---

### Langkah 3: Mengunggah Berkas (Upload)
1. Kembali ke halaman **Mitra** di panel Administrator.
2. Klik tombol **Upload** berwarna merah di sebelah tombol *Download Template*.
3. Pilih berkas spreadsheet yang sudah diisi dari komputer Anda.
4. Tunggu beberapa saat hingga sistem selesai memproses dan memvalidasi isi berkas.

---

### Langkah 4: Memeriksa Hasil Validasi & Eksekusi Impor
Setelah berkas berhasil diunggah, periksa indikator ringkasan di atas tabel hasil validasi:
* **Indikator Valid (Centang Hijau):** Menampilkan jumlah baris data yang lolos verifikasi dan siap diimpor.
* **Indikator Bermasalah (Tanda Seru Merah):** Menampilkan jumlah baris data yang ditolak oleh sistem.

#### Meninjau Tabel Validasi:

| Kolom | Keterangan & Deskripsi Fungsi |
| :--- | :--- |
| **Kolom** | Menunjukkan nomor baris lokasi data pada berkas Excel/spreadsheet Anda. |
| **Email** | Alamat email mitra yang sedang diverifikasi. |
| **Level** | Tingkatan jenjang kemitraan yang diajukan. |
| **Status** | Menampilkan hasil verifikasi sistem. Jika terjadi error, teks merah akan menjelaskan alasan spesifik penolakannya. |

#### Menyelesaikan Impor:
* Jika terdapat data bermasalah pada kolom **Status**, perbaiki baris data tersebut pada berkas Excel Anda lalu unggah kembali.
* Jika seluruh data sudah valid, klik tombol **Import Mitra** di pojok kanan bawah untuk memasukkan data mitra secara resmi ke dalam database.

## Panduan Mengatasi Masalah Validasi (Troubleshooting)

Apabila sistem menampilkan pesan error berwarna merah pada tabel validasi, gunakan tabel acuan berikut untuk mengetahui penyebab dan cara penyelesaiannya:

### 1. Masalah Akun & Role Mitra
| Pesan Error Sistem | Penyebab Utama | Solusi Penanganan |
| :--- | :--- | :--- |
| `Email "[email]" tidak ditemukan` | Email belum terdaftar pada tabel profil sistem. | Pastikan mitra sudah membuat/didaftarkan akun dasarnya di platform **Teem.id**. |
| `Email "[email]" duplikat di file ini` | Alamat email terdeteksi ditulis lebih dari 1 kali di dalam berkas Excel. | Hapus baris duplikat pada berkas Excel Anda dan tinggalkan 1 baris saja. |
| `Email "[email]" sudah terdaftar sebagai mitra sebelumnya` | Akun tersebut sudah memiliki profil mitra aktif. | Tidak perlu diimpor ulang. Kelola data mitra tersebut langsung dari menu **Kemitraan > Mitra**. |
| `Email "[email]" belum mendaftar akun di platform...` | Profil ada, tetapi belum memiliki *role external* yang sesuai. | Minta user mendaftar via aplikasi/web publik terlebih dahulu sebelum diimpor sebagai mitra. |
| `Level "[kode]" tidak dikenali` | Teks kode level kemitraan tidak sesuai dengan master *role* eksternal. | Gunakan penulisan huruf kecil standar sesuai dengan kode *role* di sistem. |

### 2. Masalah Wilayah & Alamat
| Pesan Error Sistem | Penyebab Utama | Solusi Penanganan |
| :--- | :--- | :--- |
| `Provinsi "[nama]" tidak ditemukan` | Penulisan nama provinsi tidak cocok dengan master data wilayah. | Sesuaikan ejaan nama provinsi dengan data di sistem. |
| `Kota/Kabupaten "[nama]" tidak ditemukan di provinsi tersebut` | Nama kota terdeteksi salah eja atau tidak berada di bawah provinsi yang dipilih. | Pastikan penulisan nama kota benar dan sesuai dengan hirarki provinsinya. |
| `Kecamatan "[nama]" tidak ditemukan di kota tersebut` | Nama kecamatan tidak terdaftar di dalam hirarki kota tersebut. | Cek kembali ejaan nama kecamatan sesuai data wilayah di sistem. |
| `Desa/Kelurahan "[nama]" tidak ditemukan...` | Nama desa/kelurahan tidak berada di bawah kecamatan yang diisi. | Cek kembali ejaan nama desa/kelurahan sesuai hirarki kecamatan. |

<Callout type="warn" title="Ketelitian Wilayah Berjenjang">
  Validasi wilayah bersifat **hirarkis berjenjang** (Provinsi &rarr; Kota &rarr; Kecamatan &rarr; Kelurahan). Pastikan relasi antar wilayah dari tingkat atas ke bawah sudah benar. Salah eja pada nama kecamatan akan menyebabkan desa/kelurahan di bawahnya otomatis gagal terdeteksi.
</Callout>

### 3. Masalah Format Data & Koordinat
| Pesan Error Sistem | Penyebab Utama | Solusi Penanganan |
| :--- | :--- | :--- |
| `Latitude / Longitude tidak valid` | Format koordinat salah atau bernilai di luar batas koordinat bumi. | Pastikan Latitude di rentang `-90` s/d `90` dan Longitude `-180` s/d `180`. |
| `Tanggal Mulai Kontrak kosong/format salah...` | Format tanggal bukan format standar atau sel kosong. | Ubah format kolom tanggal di Excel menjadi format standar `YYYY-MM-DD`. |
| `Bank "[nama]" tidak ditemukan` | Nama bank tidak ada pada master data perbankan sistem. | Gunakan nama bank standar yang terdaftar di master data bank. |
| `Nama Bank diisi tapi Nomor Rekening kosong` | Kolom *Nama Bank* diisi, tetapi *Nomor Rekening* ditinggalkan kosong. | Lengkapi kolom *Nomor Rekening* atau kosongkan kedua kolom tersebut sekalian jika tidak ada data bank. |

## Ringkasan Fungsi Elemen Utama

| Elemen | Jenis | Fungsi Utama |
| :--- | :--- | :--- |
| **Download Template** | Tombol | Mengunduh format acuan spreadsheet resmi. |
| **Upload** | Tombol | Mengunggah berkas Excel yang telah diisi. |
| **Badge Valid & Bermasalah** | Indikator | Ringkasan hitungan baris data yang sukses vs error. |
| **Kolom Status Tabel** | Informasi Error | Menampilkan penyebab spesifik mengapa suatu baris data ditolak sistem. |
| **Tombol Import Mitra** | Eksekusi | Menyimpan baris data yang tervalidasi ke dalam sistem. |

---

> **Tips**  
> Perhatikan nomor pada kolom **Kolom** di tabel validasi untuk menemukan baris data yang bermasalah pada berkas Excel Anda secara cepat tanpa perlu memeriksa seluruh lembar kerja satu per satu.
