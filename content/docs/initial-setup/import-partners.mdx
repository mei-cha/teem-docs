Halaman **Import Mitra** digunakan oleh Administrator untuk memasukkan data mitra dalam jumlah banyak secara sekaligus menggunakan berkas spreadsheet (Excel/CSV).

Fitur ini mempermudah proses mendaftarkan atau menyelaraskan status keanggotaan mitra lama ke dalam sistem **Teem.id** tanpa perlu menginput data satu per satu secara manual.

---

## Alur Melakukan Import Data Mitra

Proses impor data mitra wajib mengikuti 4 tahap berikut agar data dapat tervalidasi dengan benar oleh sistem.

### Langkah 1: Mengunduh Format Berkas

1. Buka modul **Kemitraan > Mitra**, lalu klik tombol **Import Mitra**.
2. Di bagian atas kotak instruksi, klik tombol **Download Template**.
3. Berkas template spreadsheet akan otomatis terunduh ke komputer.

---

### Langkah 2: Mengisi Kolom Data Spreadsheet

Buka berkas yang telah diunduh, lalu lengkapi kolom data mitra sesuai petunjuk formatnya.

#### Rincian Struktur Kolom Template

| Header Kolom | Deskripsi Pengisian |
| :--- | :--- |
| **Email** | Alamat email mitra yang terdaftar (Wajib). |
| **Level Mitra** | Tingkatan jenjang kemitraan (Wajib). |
| **NIK** | Nomor Induk Kependudukan 16 digit angka (Wajib). |
| **NPWP** | Nomor Pokok Wajib Pajak mitra (Opsional). |
| **Alamat Lengkap** | Alamat domisili atau lokasi jalan/nomor rumah (Wajib). |
| **Provinsi** | Nama provinsi domisili (Wajib). |
| **Kota/Kabupaten** | Nama kota atau kabupaten (Wajib). |
| **Kecamatan** | Nama kecamatan (Wajib). |
| **Desa/Kelurahan** | Nama desa atau kelurahan (Wajib). |
| **Latitude** | Koordinat garis lintang peta, dengan rentang -90 sampai 90 (Opsional). |
| **Longitude** | Koordinat garis bujur peta, dengan rentang -180 sampai 180 (Opsional). |
| **Nama Bank** | Nama atau kode bank resmi yang terdaftar di sistem (Opsional). |
| **Nomor Rekening** | Nomor rekening bank atau e-wallet mitra (Wajib jika Nama Bank diisi). |
| **Nama Pemilik Rekening** | Nama pemilik sesuai yang tertera pada buku tabungan (Opsional). |
| **Tanggal Mulai Kontrak** | Tanggal awal berlakunya masa aktif kemitraan dengan format standar (Wajib). |
| **Tanggal Berakhir Kontrak** | Tanggal berakhirnya kontrak dengan format standar. Kosongkan jika kontrak tidak memiliki batas waktu. |

---

### Langkah 3: Mengunggah Berkas

1. Kembali ke halaman **Mitra** di panel Administrator.
2. Klik tombol **Upload** di sebelah tombol **Download Template**.
3. Pilih berkas spreadsheet yang sudah diisi dari komputer.
4. Tunggu hingga sistem selesai memproses dan memvalidasi isi berkas.

---

### Langkah 4: Memeriksa Hasil Validasi dan Menyelesaikan Impor

Setelah berkas berhasil diunggah, periksa indikator ringkasan di atas tabel hasil validasi:

- **Indikator Valid:** Menampilkan jumlah baris data yang lolos verifikasi dan siap diimpor.
- **Indikator Bermasalah:** Menampilkan jumlah baris data yang ditolak oleh sistem.

#### Meninjau Tabel Validasi

| Kolom | Keterangan |
| :--- | :--- |
| **Kolom** | Menunjukkan nomor baris data pada berkas Excel atau spreadsheet. |
| **Email** | Alamat email mitra yang sedang diverifikasi. |
| **Level** | Tingkatan jenjang kemitraan yang diajukan. |
| **Status** | Menampilkan hasil verifikasi sistem. Jika terjadi kesalahan, sistem akan menampilkan alasan penolakan pada kolom ini. |

#### Menyelesaikan Impor

- Jika terdapat data bermasalah pada kolom **Status**, perbaiki baris data tersebut pada berkas Excel, lalu unggah kembali.
- Jika seluruh data sudah valid, klik tombol **Import Mitra** di pojok kanan bawah untuk memasukkan data mitra ke dalam sistem.

## Panduan Mengatasi Masalah Validasi

Apabila sistem menampilkan pesan kesalahan pada tabel validasi, gunakan tabel berikut untuk mengetahui penyebab dan cara mengatasinya.

### 1. Masalah Akun dan Role Mitra

| Pesan Error Sistem | Penyebab Utama | Solusi Penanganan |
| :--- | :--- | :--- |
| Email "[email]" tidak ditemukan | Email belum terdaftar pada data profil sistem. | Pastikan mitra sudah membuat atau didaftarkan akunnya di **Teem.id**. |
| Email "[email]" duplikat di file ini | Alamat email ditulis lebih dari satu kali dalam berkas Excel. | Hapus baris duplikat dan sisakan satu data untuk email tersebut. |
| Email "[email]" sudah terdaftar sebagai mitra sebelumnya | Akun tersebut sudah memiliki profil mitra. | Tidak perlu diimpor kembali. Kelola data mitra melalui **Kemitraan > Mitra**. |
| Email "[email]" belum mendaftar akun di platform | Profil pengguna belum memiliki Role yang diperlukan untuk menjadi mitra. | Minta pengguna mendaftar melalui aplikasi atau halaman publik terlebih dahulu. |
| Level "[kode]" tidak dikenali | Kode level kemitraan tidak sesuai dengan Role yang tersedia di sistem. | Gunakan kode Role sesuai dengan data yang tersedia di sistem. |

### 2. Masalah Wilayah dan Alamat

| Pesan Error Sistem | Penyebab Utama | Solusi Penanganan |
| :--- | :--- | :--- |
| Provinsi "[nama]" tidak ditemukan | Penulisan nama provinsi tidak sesuai dengan data wilayah di sistem. | Sesuaikan penulisan nama provinsi dengan data yang tersedia di sistem. |
| Kota/Kabupaten "[nama]" tidak ditemukan di provinsi tersebut | Nama kota atau kabupaten salah atau tidak berada di provinsi yang dipilih. | Pastikan penulisan nama kota atau kabupaten benar dan sesuai dengan provinsinya. |
| Kecamatan "[nama]" tidak ditemukan di kota tersebut | Nama kecamatan tidak terdaftar dalam wilayah kota atau kabupaten yang dipilih. | Periksa kembali penulisan nama kecamatan sesuai data wilayah di sistem. |
| Desa/Kelurahan "[nama]" tidak ditemukan | Nama desa atau kelurahan tidak berada di bawah kecamatan yang dipilih. | Periksa kembali penulisan nama desa atau kelurahan sesuai wilayah kecamatannya. |

<Callout type="warn" title="Ketelitian Wilayah Berjenjang">
  Validasi wilayah dilakukan secara berjenjang dari **Provinsi → Kota/Kabupaten → Kecamatan → Desa/Kelurahan**. Pastikan hubungan antarwilayah sudah sesuai. Kesalahan pada nama kecamatan dapat menyebabkan desa atau kelurahan di bawahnya tidak dapat ditemukan oleh sistem.
</Callout>

### 3. Masalah Format Data dan Koordinat

| Pesan Error Sistem | Penyebab Utama | Solusi Penanganan |
| :--- | :--- | :--- |
| Latitude / Longitude tidak valid | Format koordinat salah atau nilainya berada di luar batas koordinat bumi. | Pastikan Latitude berada pada rentang -90 sampai 90 dan Longitude pada rentang -180 sampai 180. |
| Tanggal Mulai Kontrak kosong atau format salah | Tanggal kosong atau format tanggal tidak sesuai. | Ubah format tanggal pada Excel menjadi format standar YYYY-MM-DD. |
| Bank "[nama]" tidak ditemukan | Nama bank tidak tersedia pada data bank di sistem. | Gunakan nama bank yang terdaftar pada data bank di sistem. |
| Nama Bank diisi tapi Nomor Rekening kosong | Nama Bank diisi, tetapi Nomor Rekening tidak diisi. | Lengkapi Nomor Rekening atau kosongkan kedua kolom jika data bank tidak tersedia. |

---

## Ringkasan Fungsi Elemen Utama

| Elemen | Jenis | Fungsi Utama |
| :--- | :--- | :--- |
| **Download Template** | Tombol | Mengunduh format acuan spreadsheet resmi. |
| **Upload** | Tombol | Mengunggah berkas Excel yang telah diisi. |
| **Badge Valid dan Bermasalah** | Indikator | Menampilkan jumlah data yang valid dan bermasalah. |
| **Kolom Status Tabel** | Informasi Kesalahan | Menampilkan alasan suatu data ditolak oleh sistem. |
| **Tombol Import Mitra** | Eksekusi | Menyimpan data yang telah lolos validasi ke dalam sistem. |

---

> **Tips**  
> Perhatikan nomor pada kolom **Kolom** di tabel validasi untuk menemukan baris data yang bermasalah pada berkas Excel dengan cepat tanpa perlu memeriksa seluruh lembar kerja.
