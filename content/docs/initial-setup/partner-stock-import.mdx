Halaman **Import Stok Mitra** digunakan oleh Administrator untuk memasukkan saldo persediaan barang awal (*stock cut-over*) milik mitra dalam jumlah banyak sekaligus menggunakan berkas spreadsheet (Excel/CSV) ke dalam platform **Teem.id**.

<Callout type="warn" title="Prasyarat Sebelum Impor">
  1. Pastikan mitra sudah terdaftar resmi di sistem dan memiliki **ID Mitra**.
  2. Pastikan produk sudah terdaftar pada master data modul **Produk**.
  3. Kuantitas jumlah stok pada spreadsheet wajib diisi dalam **satuan terkecil produk**.
</Callout>

---

## Cara Mengakses Halaman Import Stok Mitra

Bagi Administrator yang baru pertama kali menggunakan fitur ini, Anda dapat mengakses halaman impor dengan langkah navigasi berikut:

1. Pada bilah navigasi kiri (*sidebar*), buka modul **Kemitraan > Stok Mitra**.
2. Di baris kontrol atas (di sebelah dropdown pengurutan), klik tombol **Import Stok**.
3. Sistem akan mengarahkan (*redirect*) Anda secara langsung ke halaman **Import Stok Mitra**.

## Panduan Penggunaan & Pengisian Berkas

Setelah berada di halaman **Import Stok Mitra**, Anda dapat mengunduh berkas acuan (*template*), mengisi data persediaan mitra, dan melakukan proses validasi sebelum data disimpankan ke sistem.

### 1. Ketentuan Pengisian Berkas Template

Gunakan tombol **Download Template** pada bagian atas untuk mendapatkan format spreadsheet acuan resmi, lalu lengkapi kolom-kolomnya sesuai ketentuan berikut:

| Header Kolom | Posisi Kolom | Deskripsi & Ketentuan Pengisian |
| :--- | :--- | :--- |
| **Id Mitra** | Kolom A | Kode identifikasi unik akun mitra terdaftar (*Wajib*). Salin dari menu Daftar Mitra. |
| **SKU** | Kolom B | Kode unik identifikasi produk yang terdaftar di sistem (*Wajib*). |
| **Jumlah Stok** | Kolom C | Kuantitas persediaan barang dalam **satuan terkecil produk** (angka murni/polos > 0, *Wajib*). |

<Callout type="info" title="Aturan Penting Pengisian Berkas">
  - **Urutan Kolom Wajib Sama:** Kolom A = Id Mitra, Kolom B = SKU, Kolom C = Jumlah.
  - **Sheet Pertama:** Sistem hanya membaca lembar kerja (*sheet*) pertama pada berkas.
  - **Penulisan Angka Murni:** Tuliskan angka polos tanpa simbol mata uang, teks, atau tanda pemisah titik/koma (misal: tulis `1000`, bukan `1.000`).
  - **Satuan Terkecil:** Selalu gunakan satuan eceran terkecil (contoh: 2 karton isi 10 slop ditulis `20`).
</Callout>

---

### 2. Mengunggah Berkas & Memeriksa Hasil Validasi

1. Klik tombol **Upload** berwarna merah di sebelah tombol *Download Template*.
2. Pilih berkas Excel/CSV yang telah diisi.
3. Sistem akan membaca berkas dan menampilkan baris data pada tabel validasi.
4. **Pemeriksaan Status:** Baris bermasalah akan ditandai dengan warna merah. Baris data yang valid tetap dapat diimpor secara parsial tanpa terbatalkan oleh baris bermasalah lain.
5. **Eksekusi Akhir:** Jika data sudah tervalidasi, klik tombol **Import Stok Awal** di pojok kanan bawah untuk menyimpan data ke database.

## Panduan Penanganan Error Validasi & Peringatan

Gunakan tabel acuan di bawah ini untuk mengidentifikasi dan memeperbaiki pesan kesalahan validasi berkas:

### 1. Masalah Format File

| Pesan Error Sistem | Penyebab Utama | Solusi Penanganan |
| :--- | :--- | :--- |
| File kosong atau format tidak dikenali | Tidak ada baris data di dalam berkas. | Pastikan isi data dimulai pada baris ke-2 (baris 1 untuk header). |
| Gagal membaca file | Format berkas bukan `.xlsx`, `.xls`, atau `.csv`. | Gunakan dan unggah berkas sesuai format template resmi. |

### 2. Masalah Data Per Baris

| Pesan Error Sistem | Penyebab Utama | Solusi Penanganan |
| :--- | :--- | :--- |
| Id Mitra kosong | Kolom A tidak diisi. | Lengkapi Id Mitra pada setiap baris data. |
| Id Mitra "[kode]" tidak ditemukan | Id Mitra belum terdaftar atau terdapat *typo*. | Salin Id Mitra langsung dari menu **Kemitraan > Mitra**. |
| SKU kosong | Kolom B tidak diisi. | Lengkapi SKU produk pada setiap baris data. |
| SKU "[kode]" belum terdaftar di menu Produk | Kode SKU salah atau produk belum dibuat. | Daftarkan produk di menu **Produk** terlebih dahulu, atau periksa ejaan SKU. |
| Kombinasi Id Mitra + SKU duplikat (baris X, Y) | Pasangan mitra dan produk sama ditulis lebih dari satu kali. | Gabungkan jumlah stok menjadi satu baris dan hapus baris duplikat. |
| Jumlah Stok kosong | Kolom C tidak diisi. | Isi jumlah stok pada setiap baris data. |
| Jumlah Stok "[nilai]" tidak valid | Nilai stok berupa angka 0, negatif, desimal, atau teks. | Masukkan angka bulat positif lebih dari 0 tanpa huruf/satuan. |

### 3. Peringatan System (Warning Notification)

| Status Peringatan | Arti & Dampak System | Tindakan Pengguna |
| :--- | :--- | :--- |
| **Sudah punya stok, akan ditimpa** | Baris data tetap **Valid**, namun saldo stok mitra untuk produk tersebut akan **diganti (*overwrite*)**, bukan ditambahkan (*accumulate*). | Periksa kembali apakah nilai stok yang diinput merupakan jumlah saldo akhir terbaru mitra. |
