Halaman **Tampilkan Stok** digunakan oleh Administrator untuk mengatur apakah **stok pusat** dapat dilihat oleh pengguna eksternal pada platform **Teem.id**.

Pengaturan ini berguna jika perusahaan ingin menampilkan ketersediaan stok pusat kepada pelanggan dan mitra, atau sebaliknya menyembunyikannya.

---

## Cara Mengakses Halaman Tampilkan Stok

1. Pada bilah navigasi kiri (*sidebar*), buka modul **Administrator > Pengaturan**.
2. Pada panel navigasi sebelah kiri di bawah kategori **UMUM**, pilih sub-menu **Tampilkan Stok**.
3. Sistem akan menampilkan pengaturan **Tampilkan stok pusat ke user**.

## Mengatur Tampilan Stok Pusat

Gunakan sakelar (*toggle*) **Tampilkan stok pusat ke user** untuk menentukan visibilitas stok pusat:

| Kondisi Sakelar | Dampak |
| :--- | :--- |
| **Aktif** | Pelanggan dan mitra dapat melihat stok pusat di web utama. |
| **Nonaktif** | Stok pusat disembunyikan dari pelanggan dan mitra di web utama. |

Pengaturan ini tidak memengaruhi tampilan web admin. Administrator tetap dapat melihat stok pusat melalui modul admin.
