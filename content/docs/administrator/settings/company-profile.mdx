Halaman **Pengaturan Profil Perusahaan** adalah tahapan paling awal yang wajib dikonfigurasi oleh Administrator saat pertama kali menggunakan sistem **Teem.id**. Pengaturan ini bertujuan untuk menetapkan identitas resmi perusahaan, alamat pengiriman pusat, serta parameter dasar sistem sebelum Anda mulai mengelola produk, transaksi, dan jaringan mitra.

## Alur Konfigurasi Awal (Step-by-Step)

Ikuti urutan alur konfigurasi di bawah ini untuk menyelesaikan pengaturan identitas perusahaan:

### Langkah 1: Unggah Logo Perusahaan
1. Akses menu **Administrator > Pengaturan**.
2. Pilih tab **Profil Perusahaan** di bawah kategori **Umum**.
3. Pada bagian **Logo Perusahaan**:
   * Klik tombol **Upload Logo** pada kotak *Logo Tema Terang* untuk menampilkan logo di tampilan latar putih.
   * Klik tombol **Upload Logo** pada kotak *Logo Tema Gelap* untuk tampilan latar gelap.

### Langkah 2: Mengisi Identitas & Informasi Resmi Perusahaan
Lengkapi kolom pada blok **Profil Perusahaan** dengan data valid:
* **Branding:** Masukkan nama merek atau panggilan platform Anda 
* **Nama Perusahaan:** Masukkan nama entitas hukum resmi perusahaan 
* **No. Telp / WhatsApp:** Masukkan nomor kontak resmi untuk layanan operasional/dukungan pelanggan.
* **Email Resmi:** Masukkan alamat email bisnis utama perusahaan.
* **Jam Operasional:** Tentukan jam kerja operasional bisnis 
* **Alamat Kantor Utama:** Tuliskan alamat lengkap markas pusat perusahaan.

### Langkah 3: Menentukan Alamat Pengiriman Pusat
Pengaturan ini digunakan sebagai titik asal (*origin*) perhitungan ongkos kirim dan lokasi gudang utama saat memproses pesanan:
1. Pilih **Provinsi** lokasi pengiriman (contoh: *JAWA TIMUR*).
2. Pilih **Kota/Kabupaten** (contoh: *KOTA MALANG*).
3. Pilih **Kecamatan** (contoh: *SUKUN*).
4. Pilih **Kelurahan/Desa** (contoh: *KARANG BESUKI*).
5. Masukkan **Detail Alamat** lengkap (nama jalan, nomor bangunan, RT/RW, dan patokan lokasi).

## Ringkasan Fitur Pengaturan Administrator

Selain **Profil Perusahaan**, berikut adalah bagian-bagian pengaturan lain yang ada di navigasi samping menu **Pengaturan**:

| Kategori | Menu Pengaturan | Deskripsi Fungsi |
| :--- | :--- | :--- |
| **Umum** | Profil Perusahaan | Mengelola logo, kontak resmi, dan alamat pengiriman pusat. |
| | Tampilan | Mengatur tema visual dan kustomisasi warna antarmuka. |
| **Kemitraan** | Level | Menentukan tingkatan mitra (misal: Agen, Distributor). |
| | Deposit & Pembelian Awal | Mengatur minimal deposit dan batasan jumlah belanja perdana mitra. |
| | Dokumen Mitra | Mengatur persyaratan berkas verifikasi mitra (KTP, NIB, dll). |
| | Durasi Kontrak | Menentukan masa berlaku kerja sama atau keanggotaan mitra. |
| | Top 5 Produk | Mengatur daftar produk unggulan yang muncul pada dashboard mitra. |
| **Keuangan** | Biaya Aplikasi | Pengaturan biaya transaksi atau biaya admin platform. |
| | Otomatisasi Withdraw | Mengatur penarikan dana otomatis bagi mitra atau akun internal. |
| **Poin** | Pengaturan Poin | Menentukan rasio konversi perolehan poin dari setiap transaksi. |
| **Konten** | Banner | Mengelola gambar *banner* promosi pada aplikasi. |
