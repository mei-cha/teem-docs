Halaman **Daftar Pengguna** digunakan oleh Administrator untuk mengelola seluruh data pengguna yang terdaftar di dalam platform **Teem.id**, baik akun internal perusahaan maupun akun mitra external (Konsumen, Agen, Distributor).

## Ringkasan Ringkasan Pengguna (Summary Cards)

Di bagian atas halaman, terdapat 3 kartu informasi untuk memantau status akun:
* **Total Pengguna:** Menampilkan total akumulasi pengguna yang sudah terdaftar di sistem.
* **Pengguna Aktif:** Jumlah akun pengguna yang saat ini dalam status aktif dan dapat bertransaksi/login.
* **Pengguna Nonaktif:** Jumlah akun pengguna yang sedang ditangguhkan atau dinonaktifkan dari sistem.


## Alur Pencarian & Penyaringan Data (Step-by-Step)

1. Masuk ke menu **Administrator > Pengguna**.
2. Gunakan bar pencarian **Cari nama, email, role, level...** untuk menemukan akun tertentu secara spesifik.
3. Gunakan filter **Semua Role** untuk menyaring pengguna berdasarkan peran akun.
4. Gunakan filter **Semua Status** untuk memfilter akun berdasarkan status *Aktif* atau *Nonaktif*.


## Struktur Tabel Daftar Pengguna

| Kolom | Deskripsi Fungsi |
| :--- | :--- |
| **Nama & Gender** | Menampilkan nama lengkap serta informasi jenis kelamin pengguna. |
| **Email** | Alamat email terdaftar (dilengkapi ikon mata untuk melihat format email lengkap). |
| **No. Telepon** | Nomor kontak pengguna (dilengkapi ikon mata untuk membuka sensor nomor). |
| **Role & Level** | Menunjukkan tipe akun (*EXTERNAL*) dan tingkatan mitra (*Level: Konsumen/Distributor/dll*). |
| **Status** | Menunjukkan kondisi akun saat ini (*Aktif* / *Nonaktif*). |
| **Login Terakhir** | Catatan riwayat waktu kapan pengguna terakhir kali mengakses platform. |
| **Aksi** | Terdiri dari ikon **Pensil (Edit)** untuk mengubah data/role pengguna, dan ikon **Tempat Sampah (Hapus)** untuk menghapus akun. |
