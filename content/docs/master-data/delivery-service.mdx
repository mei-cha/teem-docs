Halaman **Master Data Ekspedisi** digunakan oleh Administrator untuk mengelola daftar penyedia jasa kurir atau ekspedisi pengiriman logistik yang didukung oleh sistem **Teem.id**.

Data ekspedisi ini berfungsi sebagai opsi pilihan pengiriman barang serta penyedia Tautan Pelacakan (*Link Tracking*) riwayat posisi pengiriman pesanan pembeli atau mitra.

---

## Cara Mengakses Halaman Ekspedisi

Bagi Administrator yang ingin mengatur atau mengonfigurasi opsi jasa kurir pengiriman, ikuti langkah navigasi berikut:

1. Pada bilah navigasi kiri (*sidebar*), buka modul **Master Data > Ekspedisi**.
2. Sistem akan menampilkan halaman utama **Ekspedisi** beserta tabel daftar kurir pengiriman terdaftar.

## Panduan Pengelolaan Jasa Ekspedisi

Administrator dapat menambahkan penyedia jasa ekspedisi baru, memeriksa tautan pelacakan, serta menyunting atau menghapus data kurir.

### 1. Menambahkan Ekspedisi Baru

1. Klik tombol **+ Tambah** berwarna merah di pojok kanan atas halaman.
2. Pada modal yang muncul, lengkapi informasi ekspedisi:
   * **Nama Ekspedisi:** Masukkan nama resmi penyedia jasa kurir (contoh: *J&T*, *KAI Logistik*).
   * **Link Tracking:** Masukkan URL standar pelacakan resi milik ekspedisi terkait.
   * **Status:** Tentukan status keaktifan layanan (*Aktif* / *Nonaktif*).
3. Klik tombol **Simpan** untuk mendaftarkan ekspedisi baru ke dalam sistem.

---

### 2. Memeriksa Tautan Pelacakan & Aksi Pengelolaan

Pada tabel utama daftar ekspedisi:

* **Link Tracking:** Klik tautan **Link ↗** pada kolom *Link Tracking* untuk membuka URL halaman resmi pelacakan resi ekspedisi di tab baru.
* **Ikon Pensil (Edit):** Membuka modal penyuntingan untuk memperbarui nama, tautan *tracking*, atau status operasional ekspedisi.
* **Ikon Tempat Sampah (Hapus):** Menghapus data ekspedisi dari sistem.

---

## Struktur Tabel Data Ekspedisi

| Kolom | Keterangan & Deskripsi Fungsi |
| :--- | :--- |
| **Nama** | Nama resmi penyedia jasa pengiriman atau kurir logistik. |
| **Link Tracking** | Tautan eksternal (*Link ↗*) menuju halaman sistem pelacakan resi pengiriman. |
| **Status** | Badge indikator keaktifan opsi ekspedisi di dalam sistem (**Aktif** / **Nonaktif**). |
| **Dibuat** | Tanggal stempel waktu (*timestamp*) saat data ekspedisi pertama kali didaftarkan. |
| **Aksi** | Tombol pintas ikon **Pensil (Edit)** dan **Tempat Sampah (Hapus)**. |
