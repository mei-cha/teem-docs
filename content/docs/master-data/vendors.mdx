Halaman **Master Data Vendor** digunakan oleh Administrator untuk mengelola data pemasok (*supplier*) atau mitra penyedia produk bagi perusahaan pada platform **Teem.id**.

Data vendor ini digunakan sebagai acuan asal-usul barang pada modul **Pembelian Stok** dan pengelolaan **Stok Perusahaan**.

---

## Cara Mengakses Halaman Master Data Vendor

Bagi Administrator yang ingin mengelola basis data pemasok/vendor, ikuti langkah navigasi berikut:

1. Pada bilah navigasi kiri (*sidebar*), buka modul **Master Data > Vendor**.
2. Sistem akan menampilkan tabel daftar seluruh vendor terdaftar.

---

## Panduan Pengelolaan Data Vendor

Administrator dapat menyaring data vendor, menambahkan entitas pemasok baru, menyunting profil, hingga mengatur status operasional vendor.

### 1. Pencarian Data Vendor

Gunakan kolom input **Cari vendor...** di pojok kanan atas tabel untuk mencari vendor berdasarkan nama, kode vendor, atau email secara *real-time*.

---

### 2. Menambahkan Vendor Baru

1. Klik tombol **+ Tambah** berwarna merah di pojok kanan atas halaman.
2. Pada modal **Tambah Vendor**, lengkapi informasi berikut:
   * **Kode Vendor:** Masukkan kode identifikasi unik vendor.
   * **Nama Vendor \***: Masukkan nama resmi perusahaan/pemasok.
   * **Kontak:** Masukkan nomor telepon/WhatsApp operasional.
   * **Email:** Masukkan alamat email resmi vendor.
   * **Alamat:** Tuliskan alamat kantor atau gudang pengiriman vendor.
   * **Vendor Aktif:** Centang kotak pilihan agar vendor berstatus aktif secara langsung.
3. Klik tombol **Tambah** untuk menyimpan data.

---

### 3. Pembaruan, Kontrol Status, & Penghapusan

Pada kolom **Aksi** di tabel utama:

* **Sakelar Toggle Status:** Klik ikon sakelar (*toggle*) untuk mengubah status vendor secara langsung (**Aktif/Nonaktif**). Vendor nonaktif tidak akan muncul pada pilihan transaksi pengadaan barang baru.
* **Ikon Pensil (Edit):** Membuka modal penyuntingan profil vendor, lalu klik **Simpan**.
* **Ikon Tempat Sampah (Hapus):** Menghapus data vendor dari sistem (hanya dapat dilakukan jika vendor belum pernah terikat transaksi pembelian stok).

---

## Struktur Tabel Data Vendor

| Kolom | Fungsi & Keterangan |
| :--- | :--- |
| **Kode** | Kode unik pengenal entitas vendor. |
| **Nama** | Nama resmi perusahaan/pemasok barang. |
| **Kontak** | Informasi nomor telepon dan email vendor (dilengkapi ikon mata untuk sensor data sensitif). |
| **Status** | Badge indikator operasional vendor (**Aktif** / **Nonaktif**). |
| **Aksi** | Tombol pintas **Toggle Status**, **Pensil (Edit)**, dan **Tempat Sampah (Hapus)**. |
