Halaman **Mitra** digunakan oleh Administrator untuk melihat dan mengelola seluruh data mitra yang terdaftar di platform **Teem.id**.

Melalui halaman ini, Admin dapat mencari dan menyaring data mitra, melihat informasi wilayah, level, status akun, serta masa berlaku kontrak. Admin juga dapat mengimpor dan mengekspor data mitra.

## Alur Mengelola Daftar Mitra

### Langkah 1: Membuka Halaman dan Mencari Mitra

1. Buka modul **Kemitraan > Mitra**.
2. Gunakan kolom **Cari mitra...** di pojok kanan atas untuk mencari mitra berdasarkan nama, ID Mitra, atau alamat email.

---

### Langkah 2: Menyaring dan Mengunduh Data Mitra

1. **Filter Data:** Klik tombol **Filter** untuk menyaring data berdasarkan kriteria tertentu, seperti level kemitraan atau wilayah.
2. **Export Data:** Klik tombol **Export** untuk mengunduh daftar mitra yang ditampilkan dalam bentuk spreadsheet.

---

### Langkah 3: Mengimpor Data Mitra

Jika ingin menambahkan data mitra dalam jumlah banyak menggunakan berkas Excel:

1. Klik tombol **Import Data Mitra** di sebelah tombol **Filter**.
2. Sistem akan membuka halaman untuk mengunggah dan memvalidasi data mitra.

<Callout type="info" title="Panduan Lengkap Impor Data">
  Untuk melihat panduan pengisian spreadsheet, pengunggahan berkas, dan cara mengatasi kesalahan validasi, silakan buka halaman **[Panduan Import Data Mitra](/docs/initial-setup/import-partners)**.
</Callout>

---

### Langkah 4: Melihat Detail Mitra

1. Cari mitra yang ingin diperiksa pada tabel.
2. Pada kolom **Aksi**, klik ikon **Mata**.
3. Sistem akan membuka halaman detail mitra yang berisi informasi identitas, alamat, kontrak, dan rekening bank.

---

## Struktur Tabel Daftar Mitra

| Kolom | Keterangan |
| :--- | :--- |
| **Id** | Menampilkan ID unik mitra. |
| **Mitra** | Menampilkan nama mitra dan alamat email. |
| **Level** | Menampilkan level mitra, seperti **Distributor**, **Agen**, **Sub Agen**, atau **Konsumen**. |
| **Wilayah** | Menampilkan kota atau kabupaten tempat mitra berada. |
| **Berakhir** | Menampilkan masa berlaku kontrak atau keterangan **Tanpa batas**. |
| **Status** | Menampilkan status akun, yaitu **Aktif** atau **Nonaktif**. |
| **Aksi** | Menampilkan ikon **Mata** untuk membuka detail mitra. |
