Halaman **Import Mitra** digunakan oleh Administrator untuk memasukkan data mitra dalam jumlah banyak (*bulk import*) secara sekaligus menggunakan berkas spreadsheet (Excel/CSV).

Fitur ini mempermudah proses mendaftarkan atau menyelaraskan status keanggotaan mitra lama ke dalam sistem **Teem.id** tanpa perlu menginput data satu per satu secara manual.

---

## Alur Melakukan Import Data Mitra (Step-by-Step)

Proses impor data mitra wajib mengikuti alur 4 tahap urut berikut agar data dapat tervalidasi dengan benar oleh sistem:

### Langkah 1: Mengunduh Format Berkas (Download Template)
1. Buka modul **Kemitraan > Mitra**, lalu klik tombol **Import Mitra** (atau akses halaman impor).
2. Di bagian atas kotak instruksi, klik tombol **Download Template** berkas.
3. Berkas *template* spreadsheet akan otomatis terunduh ke komputer Anda.

---

### Langkah 2: Mengisi Kolom Data Spreadsheet
Buka berkas yang telah diunduh, lalu lengkapi kolom-kolom data mitra sesuai petunjuk formatnya.

#### Rincian Struktur Kolom Template:

| Header Kolom | Deskripsi Pengisian |
| :--- | :--- |
| **Email** | Alamat email mitra terdaftar (*Wajib*). |
| **Level Mitra** | Tingkatan jenjang kemitraan (ditulis dengan huruf kecil). |
| **NIK** | Nomor Induk Kependudukan (16 digit angka). |
| **NPWP** | Nomor Pokok Wajib Pajak mitra. |
| **Alamat Lengkap** | Alamat domisili atau kantor mitra. |
| **Provinsi** | Nama provinsi domisili. |
| **Kota/Kabupaten** | Nama kota atau kabupaten. |
| **Kecamatan** | Nama kecamatan. |
| **Desa/Kelurahan** | Nama desa atau kelurahan. |
| **Latitude** | Koordinat garis lintang peta. |
| **Longitude** | Koordinat garis bujur peta. |
| **Nama Bank** | Nama/kode institusi perbankan pilihan mitra. |
| **Nomor Rekening** | Nomor rekening bank atau akun e-wallet mitra. |
| **Nama Pemilik Rekening** | Nama pemilik sesuai yang tertera pada buku tabungan. |
| **Tanggal Mulai Kontrak** | Tanggal awal berlakunya masa aktif kemitraan. |
| **Tanggal Berakhir Kontrak** | Tanggal kadaluarsa masa berlaku kontrak (*Kosongkan jika tanpa batas/selamanya*). |

---

### Langkah 3: Mengunggah Berkas (Upload)
1. Kembali ke halaman **Import Mitra** di panel Administrator.
2. Klik tombol **Upload** berwarna merah di sebelah tombol *Download Template*.
3. Pilih berkas spreadsheet yang sudah diisi dari komputer Anda.
4. Tunggu beberapa saat hingga sistem selesai memproses dan memvalidasi isi berkas.

---

### Langkah 4: Memeriksa Hasil Validasi & Eksekusi Impor
Setelah berkas berhasil diunggah, periksa indikator ringkasan di atas tabel hasil validasi:
* **Indikator Valid (Centang Hijau):** Menampilkan jumlah baris data yang lolos verifikasi dan siap diimpor.
* **Indikator Bermasalah (Tanda Seru Merah):** Menampilkan jumlah baris data yang ditolak oleh sistem.

#### Meninjau Tabel Validasi:

| Kolom Tabel | Keterangan & Deskripsi Fungsi |
| :--- | :--- |
| **Kolom** | Menunjukkan nomor baris lokasi data pada berkas Excel/spreadsheet Anda. |
| **Email** | Alamat email mitra yang sedang diverifikasi. |
| **Level** | Tingkatan jenjang kemitraan yang diajukan. |
| **Status** | Menampilkan hasil verifikasi sistem. Jika terjadi error, teks merah akan menjelaskan alasan spesifik penolakannya. |

#### Menyelesaikan Impor:
* Jika terdapat data bermasalah pada kolom **Status**, perbaiki baris data tersebut pada berkas Excel Anda lalu unggah kembali.
* Jika seluruh data sudah valid, klik tombol **Import [X] Mitra** di pojok kanan bawah untuk memasukkan data mitra secara resmi ke dalam database.

---

## Ringkasan Fungsi Elemen Utama

| Elemen | Jenis | Fungsi Utama |
| :--- | :--- | :--- |
| **Download Template** | Tombol | Mengunduh format acuan spreadsheet resmi. |
| **Upload** | Tombol | Mengunggah berkas Excel yang telah diisi. |
| **Badge Valid & Bermasalah** | Indikator | Ringkasan hitungan baris data yang sukses vs error. |
| **Kolom Status Tabel** | Informasi Error | Menampilkan penyebab spesifik mengapa suatu baris data ditolak sistem. |
| **Tombol Import [X] Mitra** | Eksekusi | Menyimpan baris data yang tervalidasi ke dalam sistem. |

---

> **Tips Pengguna Awam**  
> Perhatikan nomor pada kolom **Kolom** di tabel validasi untuk menemukan baris data yang bermasalah pada berkas Excel Anda secara cepat tanpa perlu memeriksa seluruh lembar kerja satu per satu.
