Halaman **Mitra** digunakan oleh Administrator untuk melihat dan mengelola seluruh data mitra yang terdaftar di platform **Teem.id**.

Melalui halaman ini, Administrator dapat mencari dan menyaring data mitra, meninjau informasi wilayah, level kemitraan, status toko, status akun, serta sisa durasi kontrak kerja sama. Selain itu, tersedia pula fitur untuk melakukan impor dan ekspor data rekapitulasi mitra.

---

## Cara Mengakses Halaman Mitra

Bagi Administrator yang ingin meninjau atau mengelola basis data mitra, ikuti langkah navigasi berikut:

1. Pada bilah navigasi kiri (*sidebar*), buka modul **Kemitraan > Mitra**.
2. Sistem akan menampilkan tabel daftar seluruh mitra terdaftar beserta indikator level, status toko, durasi kontrak, dan keaktifan akun.

---

## Panduan Fitur & Pengelolaan Data Mitra

Administrator dapat memanfaatkan fitur pencarian cepat, penyaringan parameter wilayah/level, pengaturan visibilitas kolom, ekspor-impor data spreadsheet, serta peninjauan profil detail mitra.

### 1. Pencarian, Filter & Pengaturan Tampilan

Gunakan baris kontrol di bagian atas tabel untuk mempermudah pemantauan data:

* **Pencarian Cepat:** Gunakan kolom **Cari mitra...** di pojok kanan atas untuk menyaring data berdasarkan **Nama Mitra** atau **ID Mitra**.
* **Filter Parameter:** Klik tombol **Filter** di pojok kiri atas untuk menyaring daftar mitra berdasarkan kriteria spesifik, seperti jenjang level kemitraan maupun hierarki wilayah operasional.
* **Pengaturan Kolom (Sliders):** Klik ikon **Pengaturan Kolom** di pojok kanan atas untuk memilih kolom mana saja yang ingin ditampilkan atau disembunyikan pada antarmuka tabel.
* **Export Data:** Klik tombol **Export** di pojok kanan atas untuk mengunduh rekapitulasi daftar mitra dalam format berkas spreadsheet (Excel/CSV).

---

### 2. Impor Data Mitra Baru

Untuk memasukkan data mitra baru secara massal menggunakan berkas spreadsheet:

1. Klik tombol **Import Data Mitra** yang terletak di sebelah tombol **Filter**.
2. Sistem akan mengarahkan Anda ke halaman khusus **Import Data Mitra** untuk mengunggah dan memvalidasi berkas data.

<Callout type="info" title="Panduan Lengkap Impor Data">
  Untuk melihat panduan pengisian spreadsheet, pengunggahan berkas, dan cara mengatasi kesalahan validasi, silakan buka halaman **[Panduan Import Data Mitra](/docs/initial-setup/import-partners)**.
</Callout>

---

### 3. Meninjau Detail Profil Mitra

Untuk memeriksa informasi lengkap mengenai identitas, legalitas, atau rekening mitra:

1. Cari baris nama mitra yang ingin diperiksa pada tabel.
2. Pada kolom **Aksi**, klik ikon **Mata** (Detail).
3. Sistem akan membuka halaman **Detail Mitra** yang menyajikan rincian identitas pribadi, alamat lengkap, dokumen kontrak, dan data rekening bank.

---

## Struktur Tabel Daftar Mitra

| Kolom | Keterangan & Deskripsi Fungsi |
| :--- | :--- |
| **Mitra** | Menampilkan nama lengkap mitra beserta **ID Mitra** unik di baris bawahnya (contoh: `MTR-0100`). |
| **Level** | Badge indikator level kemitraan (**Distributor**, **Agen**, **Sub Agen**, atau **Konsumen**). |
| **Wilayah** | Menampilkan lokasi kota, kabupaten, atau kecamatan domisili operasional mitra. |
| **Status Toko** | Badge indikator ketersediaan operasional toko mitra (**Online** atau kosong/offline). |
| **Berakhir** | Badge indikator sisa durasi masa berlaku kontrak kerja sama (contoh: `23 bulan 27 hari` atau `Sudah berakhir`). |
| **Status** | Badge indikator keaktifan akun mitra (**Aktif** atau **Nonaktif**). |
| **Aksi** | Tombol pintas ikon **Mata** untuk membuka halaman rincian detail profil mitra. |
