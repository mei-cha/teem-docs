Halaman Mitra digunakan untuk melihat dan mengelola data seluruh mitra terdaftar.

Admin dapat mencari dan menyaring mitra, meninjau wilayah, level, status toko, status akun, dan sisa durasi kontrak, serta mengimpor dan mengekspor data mitra.

---

## Cara Mengakses

1. Buka menu Kemitraan > Mitra.
2. Tabel mitra beserta level, status toko, durasi kontrak, dan status akun akan tampil.

## Panduan Fitur & Pengelolaan Data Mitra

### 1. Pencarian, Filter & Pengaturan Tampilan

* Pencarian: Kolom Cari mitra... di pojok kanan atas, berdasarkan Nama Mitra atau ID Mitra.
* Filter: Klik Filter di pojok kiri atas untuk menyaring berdasarkan level kemitraan atau wilayah operasional.
* Pengaturan Kolom: Klik ikon Pengaturan Kolom di pojok kanan atas untuk menampilkan atau menyembunyikan kolom.
* Export: Klik Export di pojok kanan atas untuk mengunduh daftar mitra (Excel/CSV).

### 2. Impor Data Mitra Baru

Untuk memasukkan banyak mitra sekaligus lewat spreadsheet:

1. Klik tombol Import Data Mitra di sebelah tombol Filter.
2. Anda diarahkan ke halaman Import Data Mitra untuk mengunggah dan memvalidasi berkas.

<Callout type="info" title="Panduan Lengkap Impor Data">
  Panduan pengisian dan penanganan kesalahan: [Panduan Import Data Mitra](/docs/initial-setup/import-partners).
</Callout>

### 3. Meninjau Detail Profil Mitra

Untuk melihat identitas, legalitas, atau rekening mitra:

1. Cari baris mitra yang ingin diperiksa pada tabel.
2. Pada kolom Aksi, klik ikon Mata (Detail).
3. Halaman Detail Mitra menampilkan identitas, alamat, dokumen kontrak, dan rekening bank.

## Struktur Tabel Daftar Mitra

| Kolom | Keterangan & Deskripsi Fungsi |
| :--- | :--- |
| **Mitra** | Nama lengkap mitra beserta ID Mitra unik di baris bawahnya (contoh: `MTR-0100`). |
| **Level** | Level kemitraan (Distributor, Agen, Sub Agen, atau Konsumen). |
| **Wilayah** | Lokasi kota, kabupaten, atau kecamatan domisili operasional mitra. |
| **Status Toko** | Ketersediaan operasional toko mitra (Online atau kosong/offline). |
| **Berakhir** | Sisa masa berlaku kontrak kerja sama (contoh: `23 bulan 27 hari` atau `Sudah berakhir`). |
| **Status** | Keaktifan akun mitra (Aktif atau Nonaktif). |
| **Aksi** | Ikon Mata untuk membuka halaman Detail Mitra. |
