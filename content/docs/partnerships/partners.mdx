Halaman **Daftar Mitra** digunakan oleh Administrator untuk memantau, menyaring, serta mengelola seluruh data profil jaringan kemitraan (*Distributor*, *Agen*, *Sub Agen*, hingga *Konsumen*) yang terdaftar pada platform **Teem.id**.

Melalui modul ini, Admin dapat melihat rincian informasi wilayah operasional, masa aktif masa berlaku kontrak, status keanggotaan, hingga mengekspor atau mengimpor data mitra secara masal.

## Alur Mengelola Daftar Mitra

### Langkah 1: Membuka Halaman & Pencarian Mitra
1. Masuk ke modul **Kemitraan > Mitra**.
2. **Pencarian Cepat:** Gunakan kolom input **Cari mitra...** di pojok kanan atas tabel untuk menemukan akun berdasarkan nama, ID Mitra, atau alamat email.

---

### Langkah 2: Menyaring & Mengunduh Data Mitra
1. **Filter Data:** Klik tombol **Filter** di pojok kanan atas tabel untuk membatasi tampilan data berdasarkan kriteria spesifik (seperti level kemitraan atau wilayah).
2. **Export Data:** Klik tombol **Export** untuk mengunduh seluruh daftar rekapitulasi data mitra yang tampil ke dalam berkas spreadsheet.

---

### Langkah 3: Melakukan Impor Data Mitra (Bulk Import)
Jika Anda ingin menambahkan data mitra dalam jumlah banyak sekaligus menggunakan berkas Excel:
1. Klik tombol **Import Data Mitra** di sebelah tombol *Filter*.
2. Sistem akan mengarahkan Anda ke halaman khusus proses validasi dan impor data.

<Callout type="info" title="Panduan Lengkap Impor Data">
  Untuk membaca instruksi lengkap pengisian format spreadsheet, pengunggahan berkas, hingga solusi penanganan error validasi, silakan buka halaman **[Panduan Import Data Mitra](/docs/initial-setup/import-partners)**.
</Callout>

---

### Langkah 4: Meninjau Detail Mitra
1. Cari baris akun mitra yang ingin ditinjau pada tabel utama.
2. Pada kolom **Aksi**, klik ikon **Mata (Detail)** berwarna merah.
3. Sistem akan membuka halaman rincian profil mitra mencakup identitas KTP/NPWP, alamat lengkap, masa berlaku kontrak, hingga data rekening bank.

---

## Struktur Tabel Daftar Mitra

| Kolom | Keterangan & Deskripsi Fungsi |
| :--- | :--- |
| **Id** | Kode identifikasi unik akun mitra. |
| **Mitra** | Nama lengkap mitra terdaftar beserta alamat email aktifnya. |
| **Level** | Badge tingkatan jenjang kemitraan (*Distributor*, *Agen*, *Sub Agen*, *Konsumen*). |
| **Wilayah** | Nama lokasi kota atau kabupaten tempat mitra beroperasi. |
| **Berakhir** | Sisa durasi masa aktif kontrak kemitraan (*Tanpa batas* atau hitungan bulan/hari). |
| **Status** | Badge status keaktifan akun mitra pada sistem (*Aktif* / *Nonaktif*). |
| **Aksi** | Tombol pintas ikon **Mata (Detail)** untuk membuka profil lengkap mitra. |
