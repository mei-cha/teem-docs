Halaman **Penjualan Offline** (Monitoring Penjualan Offline) digunakan oleh Admin untuk memantau transaksi penjualan langsung yang dilakukan secara luring (*offline*) oleh jaringan mitra kepada pelanggan mereka pada platform **Teem.id**.

Melalui modul ini, Admin dapat memantau produk yang ditransaksikan, nilai pembayaran tunai, serta aktivitas penjualan fisik mitra secara *real-time*.

---

## Cara Mengakses Halaman Penjualan Offline

Bagi Admin yang ingin memantau transaksi fisik mitra, ikuti langkah navigasi berikut:

1. Pada bilah navigasi kiri (*sidebar*), buka modul **Kemitraan > Penjualan Offline**.
2. Sistem akan menampilkan tabel **Monitoring Penjualan Offline** berisi daftar riwayat transaksi luring mitra.

## Panduan Fitur & Pengelolaan Monitoring

Admin dapat menyaring dan mengunduh rekapitulasi transaksi penjualan luring milik mitra:

* **Filter Periode:** Secara bawaan (*default*), tabel menampilkan transaksi **30 Hari Terakhir**. Klik tombol pemilih periode di pojok kiri atas untuk menyesuaikan rentang waktu.
* **Ekspor Data:** Klik tombol **Export** di sebelah filter periode untuk mengunduh rekapitulasi data penjualan offline ke dalam berkas spreadsheet.
* **Pencarian Cepat:** Gunakan kolom input **Cari invoice / nama mitra...** di pojok kanan atas tabel untuk menyaring transaksi berdasarkan nomor invoice atau nama mitra terkait.

---

## Struktur Tabel Monitoring Penjualan Offline

| Kolom | Keterangan & Deskripsi Fungsi |
| :--- | :--- |
| **Mitra** | Menampilkan nama lengkap mitra penjual beserta badge level kemitraan (*Distributor*, *Agen*, *Sub Agen*). |
| **Pelanggan** | Menampilkan nama pelanggan/pembeli beserta nomor ID pelanggan di baris bawahnya. |
| **Produk Dibeli** | Menampilkan rincian barang yang dibeli (nama produk, kuantitas, harga per unit, serta opsi *Lihat Semua* jika lebih dari 1 produk). |
| **Pembayaran** | Total nominal rupiah transaksi fisik beserta badge saluran pembayaran (*Tunai*). |
| **Waktu** | Informasi durasi waktu relatif sejak transaksi penjualan offline dicatat (contoh: *sekitar 1 jam yang lalu*). |
