Halaman Stok Mitra digunakan untuk memantau persediaan barang setiap mitra di berbagai wilayah.

Tersedia dua tampilan (Top 5 Produk dan Semua Produk), pencarian mitra, pengurutan stok, serta impor dan ekspor data stok.

---

## Cara Mengakses

1. Buka menu Kemitraan > Stok Mitra.
2. Matriks ketersediaan produk mitra akan tampil.

## Panduan Pengelolaan & Pemantauan Stok Mitra

### 1. Filter Wilayah & Penyaringan Data

* Pencarian: Ketik nama mitra pada kolom Cari nama....
* Filter: Klik Filter di pojok kiri atas untuk menyaring berdasarkan:
  * Level: Tingkatan kemitraan.
  * Wilayah: Provinsi, Kab/Kota, Kecamatan, hingga Desa/Kelurahan.
  * Klik Terapkan untuk memperbarui daftar.
* Pengurutan (Sort By):
  * Default: Urutan standar sistem.
  * Terbanyak / Tersedikit: Urutkan mitra berdasarkan total stok.

### 2. Memilih Mode Tampilan Stok

Pilih tab tampilan di atas tabel:

* Top 5 Produk:
  Matriks stok untuk 5 produk unggulan yang sudah dikonfigurasi. Produk tetap muncul meski stoknya `0` atau kosong (`-`). Cocok untuk membandingkan ketersediaan produk fokus antar-mitra.
* Semua Produk:
  Daftar mitra beserta wilayahnya. Klik ikon panah di sebelah nama mitra untuk melihat produk yang memiliki stok aktif. Cocok untuk memeriksa produk yang benar-benar dimiliki mitra.

<Callout type="info" title="Pengaturan Top 5 Produk">
  Jika belum dikonfigurasi, klik tautan "Atur Top 5 Produk" di bawah baris filter.
</Callout>

Klik Tampilkan (merah) untuk memperbarui tabel.

### 3. Impor & Ekspor Data Stok Mitra

* Import Stok: Klik Import Stok untuk memasukkan stok banyak mitra sekaligus lewat spreadsheet (Excel/CSV).

<Callout type="info" title="Panduan Lengkap Impor Data">
  Panduan pengisian dan penanganan kesalahan: [Panduan Stock Data Mitra](/docs/initial-setup/partner-stock-import).
</Callout>

* Export: Klik Export di kanan atas tabel untuk mengunduh data stok yang tampil sebagai spreadsheet.

## Struktur Tabel Stok Mitra

### 1. Tampilan Top 5 Produk

| Kolom | Fungsi & Keterangan |
| :--- | :--- |
| **Mitra** | Nama mitra, ID mitra, dan keterangan satuan dasar. |
| **Level** | Tingkatan kemitraan akun. |
| **[Nama Produk 1 - 5]** | Kuantitas stok untuk masing-masing dari 5 produk unggulan. |
| **Total** | Jumlah stok dari 5 produk unggulan. |

### 2. Tampilan Semua Produk

| Kolom | Fungsi & Keterangan |
| :--- | :--- |
| **Mitra** | Nama mitra, ID mitra, dan tombol panah untuk melihat rincian item produk. |
| **Level** | Tingkatan kemitraan akun. |
| **Wilayah** | Hirarki lokasi domisili/operasional mitra (Kelurahan, Kota, Provinsi). |
| **Total** | Total seluruh saldo stok produk milik mitra. |

<Callout type="info" title="Tips Pemantauan Restock">

</Callout>
