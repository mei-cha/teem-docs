Halaman **Set Target Mitra** digunakan oleh Administrator untuk mengonfigurasi dan menetapkan kuota target penjualan tahunan bagi setiap akun mitra pada platform **Teem.id**.

Administrator dapat menetapkan target secara otomatis berdasarkan wilayah menggunakan template standar, atau mengonfigurasinya secara khusus per individu mitra.

---

## Alur Mengelola Set Target Mitra (Step-by-Step)

### Langkah 1: Membuka Halaman & Memilih Tahun Target
1. Masuk ke modul **Kemitraan > Set Target**.
2. **Pengaturan Tahun:** Di sebelah judul halaman, gunakan tombol pemilih **Tahun** (seperti panah atas/bawah) untuk menentukan tahun target yang ingin ditinjau atau dikonfigurasi.
3. **Pencarian Cepat:** Gunakan kolom input **Cari...** di pojok kanan atas tabel untuk mencari mitra berdasarkan nama atau ID mitra.

---

### Langkah 2: Menggunakan Modal Set Target
1. Klik tombol **+ Set Target** berwarna merah di pojok kanan atas halaman.
2. Modal **Set Target** akan terbuka, menampilkan opsi metode penetapan target di sisi kiri dan **Hasil Preview Otomatis Sistem** di sisi kanan.

Choose salah satu metode penetapan target:

#### Opsi A: Tab Massal Per Wilayah
Metode ini digunakan untuk menerapkan target ke banyak mitra sekaligus di wilayah tertentu yang belum memiliki target.
1. Pilih **Provinsi (Filter)** dan **Kota / Kabupaten \*** tujuan.
2. Tentukan **Filter Level Kemitraan (Opsional)** jika ingin membatasi tingkatan mitra tertentu.
3. Periksa panel *Hasil Preview Otomatis Sistem* di sebelah kanan untuk melihat daftar mitra yang akan terdampak.
4. Klik tombol **Terapkan Ke [N] Mitra Terkait** untuk menyimpan.

#### Opsi B: Tab Per Mitra Spesifik
Metode ini digunakan untuk menentukan target bagi satu mitra tertentu secara individu.
1. Pilih nama akun pada dropdown **Cari / Pilih Mitra (Belum Punya Target)**.
2. Tentukan **Sumber Target Nominal**:
   * **Ikuti Template Standar:** Nominal target akan otomatis mengambil nilai acuan template kota/kabupaten mitra tersebut.
   * **Custom Manual:** Memungkinkan Admin mengisi nominal target tahunan secara manual pada kolom *Nominal Target (Tahunan)*.
3. Klik tombol **Simpan Target** untuk membukukan data.

---

### Langkah 3: Mengelola Template Target Standar
Jika ingin menentukan nilai standar acuan target tahunan berdasarkan wilayah dan level kemitraan:
1. Pada modal **Set Target**, klik tombol **Template Target** di pojok kanan atas.
2. Modal **Kelola Template Target** akan terbuka.
3. Tentukan **Tahun**, **Provinsi**, dan **Kota / Kabupaten \*** yang ingin diatur nilainya.
4. Isi batas nominal pada section **Nominal Target per Level Kemitraan**:
   * **Distributor (Tahunan)**
   * **Agen (Tahunan)**
   * **Sub Agen (Tahunan)**
5. Klik tombol **Simpan** untuk memperbarui acuan template.

---

### Langkah 4: Mengedit atau Menghapus Target Mitra
Pada tabel utama halaman **Set Target Mitra**:
* **Ikon Pensil (Edit):** Klik pada kolom **Aksi** untuk memperbarui nilai kuota target mitra yang sudah ada.
* **Ikon Tempat Sampah (Hapus):** Klik untuk menghapus penetapan target mitra pada tahun berjalan.

---

## Struktur Tabel & Modal Set Target

### 1. Tabel Utama Target Mitra
| Kolom | Fungsi & Keterangan |
| :--- | :--- |
| **Nama** | Nama lengkap dan ID unik mitra terdaftar. |
| **Kota / Kabupaten** | Lokasi wilayah operasional mitra. |
| **Level** | Badge tingkatan kemitraan (*Distributor*, *Agen*, *Sub Agen*). |
| **Tahun** | Periode tahun berlakunya kuota target. |
| **Target Tahunan** | Nominal target penjualan rupiah dalam satu tahun. |
| **Dibuat** | Tanggal pertama kali penetapan target dibuat di sistem. |
| **Aksi** | Terdiri dari tombol pintas **Pensil (Edit)** dan **Tempat Sampah (Hapus)**. |

### 2. Form Modal Set Target
| Elemen Form | Fungsi & Keterangan |
| :--- | :--- |
| **Filter Tahun Utama** | Mengunci periode tahun penetapan target mengikuti pilihan di halaman utama. |
| **Opsi Massal / Spesifik** | Pilihan penetapan target secara kolektif per daerah atau per akun individu. |
| **Ikuti Template / Custom** | Pemilihan sumber acuan nominal target (otomatis dari sistem vs input manual). |
| **Preview Otomatis** | Tabel pratinjau langsung daftar mitra dan nilai target sebelum disave. |
| **Tombol Template Target** | Membuka modal pengaturan nilai standar nominal per level kemitraan kota/kabupaten. |

---

> **Tips**  
> Atur terlebih dahulu nilai pada **Template Target** per kota/kabupaten sebelum menggunakan fitur penambahan **Massal Per Wilayah** agar proses penetapan target mitra dapat berjalan cepat dan otomatis.
