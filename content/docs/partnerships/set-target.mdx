Halaman Set Target digunakan untuk menetapkan target penjualan tahunan setiap mitra.

Target dapat dialokasikan secara kolektif per wilayah atau diatur khusus (*custom*) untuk mitra tertentu.

---

## Cara Mengakses

1. Buka menu Kemitraan > Set Target.
2. Tabel target penjualan mitra pada tahun terpilih akan tampil.

---

## Panduan Pengelolaan & Penetapan Target Mitra

### 1. Pencarian & Pemilihan Periode Tahun

Di bagian atas halaman Target Mitra:

* Filter Tahun: Pilih tahun (contoh: `2026`) di pojok kiri atas.
* Pencarian: Kolom Cari... di pojok kanan atas, berdasarkan Nama Mitra atau ID Mitra.

### 2. Massal Per Wilayah

Menetapkan target ke seluruh mitra di wilayah tertentu sekaligus. Klik + Set Target di pojok kanan atas halaman, lalu pilih tab Massal Per Wilayah.

1. Pilih mitra pada dropdown Cari / Pilih Mitra.
2. Tentukan metode nominal target:
   * Ikuti Template Standar: Nominal mengikuti template wilayah dan level mitra.
   * Custom Manual: Isi sendiri pada kolom Nominal Target (Tahunan).
3. Klik Simpan Target untuk menyimpan.

### 4. Perubahan & Penghapusan Data Target

Pada kolom Aksi di tabel utama halaman Target Mitra:

* Klik ikon Pensil (Edit) untuk memperbarui nominal target mitra.
* Klik ikon Tempat Sampah (Hapus) untuk menghapus alokasi target mitra.

---

## Struktur Tabel Target Mitra

| Kolom | Fungsi dan Keterangan |
| :--- | :--- |
| **Nama** | Nama lengkap mitra beserta ID unik mitra. |
| **Kota / Kabupaten** | Wilayah operasional atau domisili mitra. |
| **Level** | Level kemitraan (*Sub Agen*, *Agen*, *Distributor*). |
| **Tahun** | Tahun berlakunya target (misal: `2026`). |
| **Target Tahunan** | Nominal target penjualan yang ditetapkan untuk mitra. |
| **Dibuat** | Tanggal dan bulan target dibuat di sistem. |
| **Aksi** | Ikon Pensil (edit) dan Tempat Sampah (hapus). |
