Halaman Set Target digunakan untuk menetapkan target penjualan tahunan setiap mitra, baik dalam bentuk **nominal (Rp)** maupun **satuan terkecil** (total kuantitas seluruh produk).

Target dapat dialokasikan secara kolektif per wilayah atau diatur khusus (*custom*) untuk mitra tertentu.

---

## Cara Mengakses

1. Buka menu Kemitraan > Set Target.
2. Tabel target penjualan mitra pada tahun terpilih akan tampil.

---

## Panduan Pengelolaan & Penetapan Target Mitra

### Pencarian & Pemilihan Periode Tahun

Di bagian atas halaman Target Mitra:

* Filter Tahun: Pilih tahun (contoh: `2026`) di pojok kiri atas.
* Pencarian: Kolom Cari... di pojok kanan atas, berdasarkan Nama Mitra atau ID Mitra.

<Callout type="info" title="Tahun Mengikuti Halaman Utama">
  Tahun pada modal Set Target dan Template Target selalu mengikuti tahun yang dipilih pada filter Tahun di halaman utama.
</Callout>

</Callout>

#### Mengatur Template Target

Template Target menentukan target standar untuk setiap level kemitraan pada satu kota / kabupaten.

1. Pada modal Set Target, klik tombol Template Target di pojok kanan atas. Modal Kelola Template Target akan tampil.
2. Pastikan Tahun sudah sesuai (mengikuti tahun di halaman utama).
3. (Opsional) Pilih Provinsi (Filter) untuk mempersempit daftar kota / kabupaten.
4. Pilih Kota / Kabupaten (wajib). Sebelum kota dipilih, sistem menampilkan peringatan dan nominal target belum dapat diatur.
5. Pada bagian Target per Level Kemitraan, isi target untuk setiap level (Distributor, Agen, dan Sub Agen):
   * Nominal (Tahunan): target penjualan dalam Rupiah.
   * Satuan Terkecil (semua produk) (Tahunan): total kuantitas seluruh produk dalam satuan terkecil.
6. (Opsional) Klik Rincian per bulan pada masing-masing kolom untuk melihat atau mengatur pembagian target per bulan.
7. Klik Simpan untuk menyimpan template, atau Batal untuk menutup tanpa menyimpan.

### 2. Set Target Per Mitra Spesifik

Menetapkan target untuk satu mitra. Klik + Set Target, lalu pilih tab Per Mitra Spesifik.

1. Pilih mitra pada dropdown Cari / Pilih Mitra. Dropdown hanya menampilkan mitra yang belum punya target pada tahun terpilih.
2. Tentukan Sumber Target (Nominal & Satuan Terkecil):
   * Ikuti Template Standar: Nominal dan satuan terkecil mengikuti template wilayah dan level mitra.
   * Custom Manual: Isi sendiri pada kolom Nominal Target (Tahunan) dan Target Satuan Terkecil (Tahunan).
3. (Opsional) Klik Rincian per bulan untuk melihat atau mengatur pembagian target per bulan.
4. Periksa panel Hasil Preview Otomatis Sistem di sebelah kanan, yang menampilkan Nama Mitra, Level, Target Tahunan, dan Satuan Terkecil.
5. Klik Simpan Target untuk menyimpan.

<Callout type="warn" title="Nominal Target Masih Rp 0">
  Jika muncul pesan bahwa nominal target masih Rp 0, atur template kota yang valid melalui tombol Template Target, atau pilih Custom Manual untuk mengisi nominal secara langsung.
</Callout>

### 3. Perubahan & Penghapusan Data Target

Pada kolom Aksi di tabel utama halaman Target Mitra:

* Klik ikon Pensil (Edit) untuk memperbarui nominal target mitra.
* Klik ikon Tempat Sampah (Hapus) untuk menghapus alokasi target mitra.

---

## Struktur Tabel Target Mitra

| Kolom | Fungsi dan Keterangan |
| :--- | :--- |
| **Nama** | Nama lengkap mitra beserta ID unik mitra. |
| **Kota / Kabupaten** | Wilayah operasional atau domisili mitra. |
| **Level** | Level kemitraan (*Sub Agen*, *Agen*, *Distributor*). |
| **Tahun** | Tahun berlakunya target (misal: `2026`). |
| **Target Tahunan** | Nominal target penjualan yang ditetapkan untuk mitra. |
| **Dibuat** | Tanggal dan bulan target dibuat di sistem. |
| **Aksi** | Ikon Pensil (edit) dan Tempat Sampah (hapus). |
