Halaman **Set Target** digunakan oleh Administrator untuk menetapkan target penjualan tahunan bagi setiap mitra.

Target dapat ditetapkan secara bersamaan berdasarkan wilayah atau ditentukan secara khusus untuk mitra tertentu.

---

## Alur Mengelola Target Mitra

### Langkah 1: Membuka Halaman Set Target

1. Masuk ke modul **Kemitraan > Set Target**.
2. Pilih **Tahun** untuk menentukan periode target yang ingin dikelola.
3. Gunakan kolom **Cari...** untuk mencari mitra berdasarkan nama atau ID Mitra.

---

### Langkah 2: Mengatur Template Target

Sebelum menetapkan target berdasarkan wilayah, buat terlebih dahulu template target yang akan digunakan sebagai acuan.

  <img 
    src="/tamplatetarget.png" 
    alt="Kelola Template Target" 
    className="max-h-[380px] w-auto mx-auto rounded-lg shadow-sm" 
  />
  <span className="block text-xs text-gray-400 mt-2">
    Modal Kelola Template Target

1. Klik tombol **+ Set Target** di pojok kanan atas.
2. Pada modal **Set Target**, klik **Template Target**.
3. Pada modal **Kelola Template Target**, tentukan:
   * **Tahun** target.
   * **Provinsi**.
   * **Kota / Kabupaten**.
   * **Target Distributor**.
   * **Target Agen**.
   * **Target Sub Agen**.
4. Klik **Simpan** untuk menyimpan template.

Template ini menjadi acuan nominal target berdasarkan wilayah dan level mitra.

<Callout type="warn" title="Penting">
  Template Target harus diatur terlebih dahulu jika ingin menggunakan penetapan target **Massal Per Wilayah** atau memilih **Ikuti Template Standar** pada penetapan target per mitra.
</Callout>

---

### Langkah 3: Menetapkan Target Mitra

Setelah template tersedia, target dapat ditetapkan dengan dua cara.

#### Opsi A: Massal Per Wilayah

<div className="my-4 text-center">
  <img 
    src="/settarget1.png" 
    alt="Modal Set Target Massal Per Wilayah" 
    className="max-h-[380px] w-auto mx-auto rounded-lg shadow-sm" 
  />
  <span className="block text-xs text-gray-400 mt-2">
    Modal Set Target - Massal Per Wilayah
  </span>
</div>

Opsi ini digunakan untuk menetapkan target kepada beberapa mitra sekaligus berdasarkan wilayah.

1. Pilih **Provinsi**.
2. Pilih **Kota / Kabupaten**.
3. Jika diperlukan, pilih **Level Kemitraan** untuk membatasi mitra berdasarkan level tertentu.
4. Sistem akan menampilkan daftar mitra yang sesuai beserta nominal target berdasarkan Template Target.
5. Periksa daftar mitra dan nominal target pada bagian pratinjau.
6. Klik **Terapkan ke [N] Mitra Terkait** untuk menetapkan target kepada seluruh mitra yang ditampilkan.

---

#### Opsi B: Per Mitra Spesifik

<div className="my-4 text-center">
  <img 
    src="/settarget2.png"

    className="max-h-[380px] w-auto mx-auto rounded-lg shadow-sm"

  <span className="block text-xs text-gray-400 mt-2">
    Modal Set Target - Per Mitra Spesifik
  </span>
</div>

Opsi ini digunakan untuk menetapkan target kepada satu mitra tertentu.

1. Pilih mitra pada bagian **Cari / Pilih Mitra**.
2. Pilih sumber nominal target:
   * **Ikuti Template Standar:** Menggunakan nominal target yang sudah ditentukan berdasarkan wilayah dan level mitra.
   * **Custom Manual:** Menentukan sendiri nominal target untuk mitra tersebut.
3. Jika memilih **Custom Manual**, masukkan nominal pada kolom **Nominal Target (Tahunan)**.
4. Klik **Simpan Target** untuk menyimpan target mitra.

---

### Langkah 4: Mengubah atau Menghapus Target

Pada tabel utama **Set Target**, gunakan kolom **Aksi** untuk mengelola target yang sudah ditetapkan:

* Klik ikon **Pensil** untuk mengubah nominal target.
* Klik ikon **Tempat Sampah** untuk menghapus target mitra.

---

## Struktur Tabel Set Target

| Kolom | Fungsi dan Keterangan |
| :--- | :--- |
| **Nama** | Nama mitra dan ID Mitra yang memiliki target. |
| **Kota / Kabupaten** | Wilayah tempat mitra beroperasi. |
| **Level** | Tingkatan kemitraan mitra. |
| **Tahun** | Tahun berlakunya target. |
| **Target Tahunan** | Nominal target penjualan yang harus dicapai dalam satu tahun. |
| **Dibuat** | Tanggal target ditetapkan. |
| **Aksi** | Tombol untuk mengubah atau menghapus target. |

---

## Struktur Form Set Target

| Elemen | Fungsi dan Keterangan |
| :--- | :--- |
| **Tahun** | Menentukan tahun target yang akan ditetapkan. |
| **Massal Per Wilayah** | Menetapkan target kepada beberapa mitra berdasarkan wilayah secara bersamaan. |
| **Per Mitra Spesifik** | Menetapkan target kepada satu mitra tertentu. |
| **Template Target** | Mengatur nominal target berdasarkan wilayah dan level mitra. |
| **Ikuti Template Standar** | Menggunakan nominal target yang sudah ditentukan pada Template Target. |
| **Custom Manual** | Memasukkan nominal target secara manual untuk mitra tertentu. |
| **Pratinjau** | Menampilkan daftar mitra dan nominal target sebelum target diterapkan. |
| **Simpan Target** | Menyimpan target untuk mitra yang dipilih. |
| **Terapkan ke [N] Mitra Terkait** | Menetapkan target kepada seluruh mitra yang sesuai dengan wilayah dan filter yang dipilih. |
