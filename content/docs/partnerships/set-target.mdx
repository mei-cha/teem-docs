Halaman **Set Target** digunakan oleh Administrator untuk menetapkan target penjualan tahunan bagi setiap mitra pada platform **Teem.id**.

Administrator dapat mengalokasikan target penjualan secara kolektif berdasarkan wilayah operasional maupun menentukan besaran target secara khusus (*custom*) untuk mitra tertentu.

---

## Cara Mengakses Halaman Set Target

Bagi Administrator yang ingin mengatur atau mengelola target penjualan mitra, ikuti langkah navigasi berikut:

1. Pada bilah navigasi kiri (*sidebar*), buka modul **Kemitraan > Set Target**.
2. Sistem akan menampilkan tabel daftar target penjualan mitra sesuai dengan periode tahun yang dipilih.

---

## Panduan Pengelolaan & Penetapan Target Mitra

Administrator dapat membuat template acuan wilayah, mengalokasikan target secara massal, hingga menyesuaikan nominal target mitra secara spesifik.

### 1. Pencarian & Pemilihan Periode Tahun

Pada baris kontrol utama halaman **Target Mitra**:
* **Filter Tahun:** Pilih **Tahun** (contoh: `2026`) pada pemilih periode di pojok kiri atas untuk menyaring atau menampilkan daftar target pada tahun berjalan.
* **Pencarian Cepat:** Gunakan kolom **Cari...** di pojok kanan atas untuk menemukan data target berdasarkan **Nama Mitra** atau **ID Mitra**.

---

Opsi ini digunakan untuk mengonfigurasi besaran target bagi satu akun mitra secara khusus:

1. Pilih akun mitra pada menu dropdown **Cari / Pilih Mitra**.
2. Tentukan metode nominal target:
   * **Ikuti Template Standar:** Menggunakan besaran nominal acuan berdasarkan wilayah dan level mitra.
   * **Custom Manual:** Memasukkan nominal target secara fleksibel/manual pada kolom **Nominal Target (Tahunan)**.
3. Klik tombol **Simpan Target** untuk menyimpan penetapan.

---

### 4. Perubahan & Penghapusan Data Target

Pada kolom **Aksi** di tabel utama halaman **Target Mitra**:
* Klik ikon **Pensil (Edit)** untuk memperbarui besaran nominal target mitra.
* Klik ikon **Tempat Sampah (Hapus)** untuk membatalkan/menghapus alokasi target mitra dari sistem.

## Struktur Tabel & Form Set Target

### 1. Struktur Tabel Utama Target Mitra

| Kolom | Fungsi dan Keterangan |
| :--- | :--- |
| **Nama** | Nama lengkap mitra beserta ID unik mitra terdaftar. |
| **Kota / Kabupaten** | Wilayah operasional atau domisili mitra. |
| **Level** | Badge indikator tingkatan level kemitraan (*Sub Agen*, *Agen*, *Distributor*). |
| **Tahun** | Kolom penunjuk periode tahun berlakunya alokasi target (misal: `2026`). |
| **Target Tahunan** | Nominal akumulasi target penjualan yang ditetapkan untuk mitra. |
| **Dibuat** | Tanggal dan bulan penetapan target dibuat di sistem. |
| **Aksi** | Tombol ikon untuk menyunting (*Pensil*) atau menghapus (*Tempat Sampah*) target. |

### 2. Ringkasan Elemen Form

| Elemen Form | Tipe | Fungsi & Keterangan |
| :--- | :--- | :--- |
| **Tahun** | Dropdown | Menentukan periode tahun berlakunya alokasi target. |
| **Massal Per Wilayah** | Opsi Tab | Moda alokasi target kolektif berbasis wilayah operasional. |
| **Per Mitra Spesifik** | Opsi Tab | Moda alokasi target individu untuk mitra tertentu. |
| **Template Target** | Tombol | Membuka modal pengaturan nominal standar wilayah. |
| **Ikuti Template Standar** | Radio | Menggunakan besaran nominal acuan dari template wilayah. |
| **Custom Manual** | Radio | Memasukkan nominal target secara manual. |
| **Pratinjau** | Tabel Ringkas | Menampilkan daftar mitra penerima target sebelum dikonfirmasi. |
| **Simpan Target / Terapkan** | Eksekusi | Menyimpan penetapan target ke dalam database sistem. |
